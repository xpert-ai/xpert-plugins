## 复验

按[安装说明](setup.md)执行依赖安装、`typecheck`、`test`、`build`、`verify:dist` 及真实平台脚本。从仓库根目录按 `plugin-dev-harness/README.md` 准备工具后运行：

```sh
NODE_PATH="$PWD/community/apps/manufacturing-quotation/node_modules" node scripts/check-plugin-metadata.mjs --package community/apps/manufacturing-quotation
node plugin-dev-harness/dist/index.js --workspace ./community/apps/manufacturing-quotation --plugin @xpert-ai/plugin-manufacturing-quotation
```

`NODE_PATH` 复用插件的 TypeScript。验收脚本与合成 PNG 在 `acceptance/`，各次运行的 JSON 和截图写入被 Git 忽略的 `acceptance/.local/`。按顺序运行，避免并行浏览器争用导致超时。

## 边界

- 模型可能误判；历史上“黑袋”曾被识别成 b，后端以 `invalid_grade` 拒绝且未生成报价。提示词不能替代服务端校验和人工核对。
- JPEG/WebP 未分别调用真实模型；网络中断、OCR 超时及迟到写入由单测/模拟覆盖。并发检查是少量请求的正确性验收，没有生产容量压测、真实网络/数据库故障注入、客户验收或 Cloud 托管环境验收。
- 个人绑定的默认助手保留在嵌入式侧栏，依赖 `xpert` 仓库的独立补丁。该补丁不在插件 PR 中；宿主构建、4 项列表断言和浏览器验收通过，组件 Jest 未运行。
- 跨账号详情 GET 与动作接口的错误形式不同，均未返回他人记录。平台可选 sandbox 请求曾返回 403；本助手未启用沙箱，报价流程通过。入口消息提交验收不等于模型生成成功。
