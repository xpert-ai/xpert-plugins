# 限制边界

## 尚未完成或缺少验证

- 应用尚无包含当前修改的正式测试 commit；开发开始 main 基线缺历史证据，现有 HEAD 不冒充基线。
- 未在全新机器／干净依赖环境完成复现；本地开发依赖目录仍借用相邻包，冻结锁记录校验不替代独立安装验证。
- 独立模板列表／详情、整页刷新恢复、重试 roundId 对照缺证据。按当前交付计划不新增截图，以未验证标注。
- 两个真实组织账号的非法读取、写入隔离未验证；数据库级查询范围测试不是完整授权验收。
- 真实平台删除完成、模型故障及数据库记录无重复未完整核验。
- 原生 HTML 工作台未迁移为共享 shadcn 与 typed i18n；界面源码集中维护，未实现远程分页。

## 适用边界

| 范围 | 当前边界 |
| --- | --- |
| 数据来源 | 固定 Mock 商品 6543210—6543219；不抓取淘宝、不代表真实价格 |
| AI | 提供判断与建议，可能出错；人工审核，不自动执行店铺操作 |
| 并发 | 单 API 进程；内存范围锁不能保护多个 API 实例的并发 |
| 数据范围 | 使用宿主租户、组织上下文；清理必须有明确组织 |
| 展示数量 | 商品 50、轮次 20、变化和建议各 100；界面统计不是全量 |
| 清理 | 不可恢复，事务保障原子性；分析在途会阻止删除，中断需结束或报告失败 |
| 建议重建 | 单独删除建议保留变化，再次分析可能生成新建议 |
| 环境 | 依赖 Xpert 宿主、数据库、缓存与可用模型；不是无环境依赖的独立桌面软件 |

## 后续最值得改进的方向

1. 固定提交和测试版本，完成独立依赖安装及干净环境复现。
2. 验证真实账号授权和数据库持久化边界，添加稳定的宿主集成回归。
3. 为多实例引入统一数据库锁，并完善分析取消／异常退出恢复。
4. 增加远程分页，迁移共享组件与多语言规范，分离界面职责。
5. 接入获得授权的真实数据源，完善证据质量、限流和采集监控，再评估运营价值。

以上是后续工作，不宣称已经实现或验证。实际结果见 [测试报告](测试报告.md)。
