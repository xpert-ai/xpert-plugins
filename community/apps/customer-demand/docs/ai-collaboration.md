# AI 协作说明

本项目在 AI 编程协作下完成，人工负责选题、业务边界和验收目标，AI 负责代码实现、测试设计、文档整理和浏览器回归。开发过程没有把生成结果直接当成正确答案，而是通过 SDK 类型、Xpert 插件契约、服务测试、官方加载器、共享 Remote View 宿主和真实 Jev 调用逐层验证。

主要协作方式：

- 先阅读面试说明、Xpert 插件开发约束和 TypeSafe 实时文档，再确定“模型做结构化判断，代码控制流程，人工做最终确认”的架构。
- 用 AI 生成初稿后，针对范围隔离、幂等、并发租约、失败重试和消息边界补充反例测试。
- 通过真实浏览器走完整流程，发现并修正宿主 `hostEvent` 与查询结果载荷格式不同的问题。
- 用真实 Jev 记录解析模型名和行为证据，同时使用固定 fixture 保证 UI 复现不依赖额度。
- 所有示例客户均为合成数据；没有把真实客户聊天内容发送到模型或提交到仓库。

AI 没有代替人工做业务阈值校准、真实用户研究或生产安全评审。优先级规则、置信度阈值与协作范围仍需要基于企业样本决定。
