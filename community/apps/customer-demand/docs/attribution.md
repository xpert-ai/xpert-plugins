# 第三方来源与许可

- Xpert 插件 SDK、Contracts 与宿主 Remote View 协议来自 `xpert-ai/xpert` 和 `xpert-ai/xpert-plugins`，项目随仓库采用 AGPL-3.0。
- 结构化判断通过 `@typesafe-ai/sdk` 调用 TypeSafe Jev；API 服务和 SDK 的使用受各自条款与许可证约束。
- UI 使用 React、Radix UI、Tailwind CSS、Lucide 图标以及由 shadcn CLI 生成并纳入源码的组件。
- 服务使用 NestJS、TypeORM、Zod；独立预览使用 SQL.js。

仓库中没有复制第三方产品截图、客户数据、商标素材或生成式图片。截图只包含本项目界面和合成业务示例。各依赖的精确版本见 `package-lock.json`。
