# AI 协作说明

## 工具与模型

- 开发工具：Cursor（Composer）
- 运行时模型：DeepSeek（`deepseek-v4-flash`），在本地 Xpert 中真实调用

## 代表性过程

1. **选题与范围**：按面试任务书选择「农服工单智能填报」，对齐「明确用户 + 一条流程 + 真实 AI + 保存/恢复 + 失败重试」。  
2. **实现策略**：阅读 `community/apps/smart-maintenance` 后改造为农服语义，而不是从零搭脚手架，以控制时间并保证可运行。  
3. **联调取舍**：工作台视图在 Chat 宿主下曾 404；优先保证对话链路可演示，并在 README 标明限制，而不是阻塞交付。  
4. **验证**：用完整需求与故意不完整需求各跑通一次，截图放入 README。

## 收获

在有限时间内，用官方示例骨架换业务语义是更稳妥的交付路径；平台宿主差异（工作台激活）应尽早用最小路径验证，避免把时间耗在非核心 UI 上。
