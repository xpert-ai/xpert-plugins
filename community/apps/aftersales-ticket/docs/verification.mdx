## 2026-11-28 收尾版

构建：共享 shadcn UI、TypeScript、esbuild 浏览器资源通过。`corepack pnpm test` 共 17 项，全部通过。
新增服务层测试：超时后两个请求竞争仅一个成功；旧 attempt 不能保存/报失败；updatedAt 在读取后改变时拒绝过期接管。模板测试检查 xpert/data-xpert、两个 Workbench slot 和确认不发送的约束。

测试使用内存 Repository；远程 UI 使用 jsdom 和模拟宿主消息。它们不替代真实 PostgreSQL 并发、跨账号权限或真实模型输出验收。

## 前一版真实平台证据

操作者完成：客服角色登录、Workbench 新建与查看、DeepSeek 分析、人工确认、刷新恢复；截图在 README 使用相对路径展示。失败重试通过直接修改测试工单 updatedAt 模拟超时，再调用分析工具成功取得 attempt 2；没有实测自然等待五分钟。

重试截图里模型错误称另一工单已发送。应用没有发送接口，confirmed 仅表示审核保存。本轮修复模板说明、工具描述及返回数据，并保留历史截图说明问题。不能用模型的口头声明证明权限边界，也不能用工具配置开关证明实际工具调用。

## 尚待平台复验

- 从 xpert 模板列表创建新助手，确认模板可见、连接存在、选择模型并发布；旧助手不会自动获得新模板提示词。
- 新助手走完一次分析与人工修改确认，核查模型不再把 confirmed 说成已发送。
- 展开 begin_analysis/save_analysis 调用输入输出并补截图；验证相同 ID、attempt 与持久化结果一致。
- 不改数据库，通过“标记分析中断”→重试走一次恢复；跨用户/跨组织接口拒绝与真实 DB 并发另测。
- 键盘、读屏、移动端不是本轮完成项。

运行环境为本地源码 API/Cloud UI + Docker 基础设施，不是远程云部署。安装方式、重启要求和已知本地偏差见 deployment.md。
