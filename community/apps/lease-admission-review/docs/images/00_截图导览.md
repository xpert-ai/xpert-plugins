# 截图导览

按文件名升序查看：01–06 为输入、AI候选、人工核验、草稿、确认与恢复；07–09 为异常/规则分支；10–13 为账号与布局补充；90–95 保留历史版本证据。

全部图片来自实际 Xpert 宿主中的插件视图，使用合成材料。不是设计稿或模拟页面。为避免配置和账号信息进入截图，仅截取工作台区域。编号表示阅读顺序，并非同一案例一次连续执行的录像；01是未提交输入，02/03/05/06读取已有确认案例，04/07读取既有缺失案例。模型真实性、重试成功、数据隔离和持久化还需结合测试记录，不能只凭静态截图判定。

原要求中的截图范围已覆盖：关键界面、用户输入、AI处理结果、至少一个异常；插件README直接用相对路径显示主流程图片。完整交付仍包含源码、运行说明、测试证据、AI协作与复用说明以及经授权提交的PR，截图不是全部交付。
