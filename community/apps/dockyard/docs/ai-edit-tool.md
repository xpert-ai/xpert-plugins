# AI 修改并保存（0.4.0）

状态：已按用户授权部署到本任务本地实例、重启 API 并更新发布原助手。0.3.0 的截图、真实模型回执和历史说明不证明本版运行验收。

## 使用

1. 在工作台成功保存文件，选中文字或右键文件，选择“帮我改”。
2. 插件核对文本与已保存版本一致，将版本附在聊天引用标签中；未保存时提示先保存。
3. 在聊天中明确说明如何修改，然后发送。缺少修改目标时，助手先问清楚。
4. 助手调用 `dockyard_edit_file`，用路径、引用版本、唯一原文和替换文本修改数据库中的已有文件。
5. 只有成功回执才表示已保存。0.4.1 会在工作台可见时每 5 秒检查保存版本，并在窗口重新获得焦点时检查；无本地修改的编辑器自动更新。有未保存编辑时保留原文并提示版本冲突。旧编辑器保存会被版本检查拒绝，不会覆盖 AI 结果。

“解释一下”只回答；工具不创建文件、不读出其他文件、不改布局、不执行代码。不增加复杂 AI 面板，也不改宿主或 ChatKit。

## 保存边界

- 身份范围来自宿主中间件上下文，不来自模型参数。
- 版本不一致、原文未出现、原文重复或文件不存在时拒绝保存。
- 写入复用数据库 compare-and-swap，竞争修改只能有一个成功；同一旧版本重放会被拒绝。
- 替换可为空，支持删除选中内容或清空已有文件。
- 客户端和模板负责说明修改意图；服务端提供范围、版本和原文检查，不把提示词当作权限机制。
- 暂无独立“应用”按钮，明确的用户修改请求授权模型调用工具；如需逐项审核，应另设计确认流程。

## 生效步骤

重新构建并部署插件，按安装回执重启目标 API，再对原助手更新模板并发布。没有执行这些步骤前，编排页仍可能显示“无工具”。不要重复创建助手。
