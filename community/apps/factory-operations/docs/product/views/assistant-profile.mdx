---
title: 'Assistant 资料卡'
description: '查看实例负责的 Factory Case，并通过项目流水线审批'
---

在侧栏 Assistant 入口悬停或点击资料按钮，打开资料卡。顶部固定显示 Assistant 资料，下方“基本信息”“最近案件”“待处理”在同一卡片内切换。聊天页头也提供入口。

## 案件归属与查看权限

“最近案件”按更新时间倒序展示每页 10 条 Factory Case，包含设备、严重度、进展、最近变化和下一步。点击案件进入卡内详情，查看方案、证据和执行情况。

案件归属取 Case Project 明确分配与执行记录 requester / executor 的并集，包含同一 Assistant 的发布版本；同名或同角色的另一实例不会自动获得案件。后端先应用租户、组织、Project 可读权限和实例归属，再分页与统计。

“待处理”显示待人工审批的案件。技术执行失败、取消与重试在项目流水线中处理。Project 可读成员可以查看；只有 owner / manager 可以审批。Agent 工具和 editor / member 不具备人类审批权。

## 审批与继续

1. 在待审批 Factory Case 中查看当前方案、Case 与方案修订以及模拟或外部模式。
2. 提交批准或拒绝决定与意见，取消不产生写入。
3. 服务端核对 owner / manager 权限并提交平台人工关口。平台随后派发审批落账；批准分支继续执行与验证，拒绝分支进入人工处理。
4. 只有匹配的业务 finalizer 确认恢复、证据与执行记录均已保存，案件才成为 `recovered`。

Profile 与 Workbench 共用同一个人工关口，没有独立的“审批后续跑”状态机。关闭资料卡不影响平台调度。查看执行失败、重试、取消或历史轮次时，打开项目流水线。

模拟模式只产生明确标记的模拟确认。外部适配器未配置时明确失败，不生成生产执行成功结果。

## 加载行为

插件 Feature 为 `factory-assistant-profile`，共享于现有工厂角色 middleware。两个 manifest 使用 `agent.profile.tabs`。tab 首次选中时加载；已访问的 iframe 在资料卡内缓存。隐藏 tab 接收 `viewActive: false` 后暂停轮询，切回先展示缓存并从下一个周期继续刷新。关闭资料卡或切换 Assistant 时释放全部 iframe、请求、订阅和轮询。

确认弹窗及提交期间保持资料卡打开，禁止切换 tab。Escape 先关闭弹窗；关闭资料卡后恢复入口焦点。
