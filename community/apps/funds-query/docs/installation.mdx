# 资金交易问数安装说明

插件版本 **0.2.4**。上传安装时选择 **funds-query-0.2.4.zip**。

## 安装条件

- Xpert 前后台已启动，可打开 http://localhost:4200 。
- 使用具有租户级插件管理权限的账号登录，进入租户范围。
- Xpert 服务器已有 Python 3.11+。当前本机已有 Python 3.12。
- 使用配套的 ChatKit 0.21.1+funds.2 平台接入构建，当前工作区已配置。

安装包提供 Excel 解析所需的纯 Python 依赖，工作台自动检测解释器。安装包包含构建完成的 Vue 界面及原生插件入口。

## 1 页面上传

1. 打开 Xpert 的“插件”管理页，本机地址为 http://localhost:4200/plugins 。
2. 点击“安装插件”，选择“压缩包”。
3. 点击“选择文件”，选择 `funds-query-0.2.4.zip`。
4. 点击“安装”，等待提示安装完成。

`funds-query-source-0.2.4.zip` 用于开发和源码审查。上传安装请选择上面的正式安装包。

## 2 重启生效

若页面提示“需要重启 API 服务”，点击“立即重启”，再在确认对话框中点击“立即重启”和“确认重启”。等待页面恢复，插件列表中的“资金交易问数”应显示版本 0.2.4，并完成加载。

本机启动脚本已加入明确的平台重启通知处理。平台发出重启请求后会重新执行启动检查并加载插件，手动停止平台仍会结束进程。

## 3 打开助手

当前本机已保留资金问数助手的配置。安装生效后，打开已有的“资金交易问数助手”，关闭并重新打开资金问数工作台。

首次使用新组织时，先为组织配置支持工具调用的默认主模型，再到 Explore 应用市场，将“资金交易问数”应用到该组织。

工作台顶部应显示“运行环境已就绪 · Python …”。如果提示缺少 Python，由服务器管理员安装 Python 3.11+，然后点击工作台“刷新”。

## 4 按需调整配置

在插件卡片的操作菜单中打开“配置”。

| 配置项 | 默认行为 |
| --- | --- |
| Python 解释器 | auto，自动选择可用的 Python 3.11+ |
| 持久化数据目录 | 服务器用户目录下的 .local/share/xpert-funds-query |
| 分析超时毫秒数 | 30000 |
| 运行诊断日志 | 关闭 |

解释器也可填写服务器上的命令或绝对路径。数据目录应位于可读写的持久化磁盘。保存配置后按平台提示重启生效。

## 5 导入与测试

**当前仅支持标准格式的 .xlsx 交易文件。** 首个工作表使用固定列顺序，账号为文本，金额为大于零且最多两位小数的人民币金额。完整字段格式见 [README](../README.md#数据导入范围)。

招聘方可下载 [标准模板](../examples/标准导入模板.xlsx) 和 [标准样例](../examples/交易明细-标准样例.xlsx) 进行测试，所有数据均为合成。其他测试文件及预期答案见 [examples](../examples/)。

首次使用时工作台显示空数据提示。重复导入相同文件会复用已有数据集。

上传 `交易明细-标准样例.xlsx`，预期显示 12 笔交易，总额 102566.91 元。新建会话，提问“张三在2026年10月一共收了多少钱，有几笔？”，预期 90000.13 元、4 笔。

接着问“只看超过5万元的”，预期 60000.00 元、1 笔。再问“全部收款呢”，预期回到 90000.13 元、4 笔。

完整步骤见[测试流程](acceptance.mdx)。插件包的 examples 目录提供所有合成样例。


## 平台准备

当前版本适配配套的 ChatKit 0.21.1+funds.2 构建。迁移时由管理员核对平台接入补丁和本地启动脚本修改，再按页面流程上传。Python 及数据目录应位于 Xpert API 运行环境中。
