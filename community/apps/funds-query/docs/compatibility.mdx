| 部分 | 修改内容 | 证据与交付 |

## 平台故障确认

任务书允许向招聘方提交版本、复现步骤和脱敏证据，由招聘方确认平台问题。候选人需要确认面试方接受的测试基线、是否允许该补丁，以及是否需要单独关联平台修复 PR。

建议反馈的复现步骤如下。

1. 在上述平台和插件基线上安装资金问数，初始化模板并打开工作台。
2. 完成标准样例十月收款问题，随后在同一会话追问金额筛选。
3. 核对原生会话恢复回执、平台执行记录与插件已保存问题是否一致。
4. 对照补丁中的会话确认、发送目标校验和输入区归属修改。
5. 若核对页面重启，在源码启动方式下检查平台重启请求与子进程退出后的重新加载。

当前平台故障归属及补丁接受方式等待招聘方确认。代码和测试结果如实记录这一依赖。

## 复现准备

平台与插件使用各自 packageManager 和 Node.js 要求。插件工作区采用 Node.js 22.23.4、pnpm 8.15.8，Python 3.12.13。ChatKit 构建采用 Node.js 24.15.0、pnpm 10.11.0。

先应用 [ChatKit 补丁](platform/chatkit.patch)，在该仓库安装固定依赖并构建 chatkit-ui。将该包输出为 chatkit-ui-0.21.1-funds-followup-fix.tgz，置于与平台补丁依赖覆盖对应的 deliverables 目录，再应用 [Xpert 补丁](platform/xpert.patch)。路径应按测试目录布局核对。

```bash
# 在 ChatKit 仓库中，选择符合该仓库要求的 Node.js。
corepack pnpm install --frozen-lockfile
corepack pnpm --filter @xpert-ai/chatkit-ui build
corepack pnpm --filter @xpert-ai/chatkit-ui types
cd packages/chatkit-ui
corepack pnpm pack --out /absolute/path/to/deliverables/chatkit-ui-0.21.1-funds-followup-fix.tgz
```

在平台中安装已准备的锁文件并重新启动前后台，然后按安装文档上传插件。插件源码构建和测试步骤见 README。外置平台的归档解析器测试通过 XPERT_PLATFORM_ROOT 指向平台目录。
