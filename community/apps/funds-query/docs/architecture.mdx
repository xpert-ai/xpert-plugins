## 处理流程

标准 Excel 导入后由 Python 校验并保存。用户提问时，Xpert 模型确认账户和日期，将问题转为受限查询条件，调用 Python 精确计算。Vue 展示文字回答、统计卡片、排行或趋势，以及原始交易依据。

| 层 | 职责 |
| --- | --- |
| Python | Excel 校验、SQLite 持久化、账号解析、日期窗口、整数分计算、分页 |
| Vue | 导入、数据集和会话选择、聊天时间线、处理状态、结果与证据 |
| TypeScript | Xpert 插件注册、助手模板、工具、中间件、View 和 Python 进程调用 |

Python 在隔离模式下使用随包的纯 Python 依赖，通过 stdin/stdout 交换 JSON。解释器默认自动检测，也可在图形配置页面指定。运行依赖随包提供，持久化目录位于服务器用户目录下。模型使用平台配置，通过声明的分析工具访问数据。

## 文件与身份

一个文件对应一个数据集。支持首个工作表、10 MiB 文件、5000 笔交易，解压体积上限 64 MiB。账号为文本，金额大于零且最多两位小数。文件校验按整批处理，有错误时返回 Excel 行号及原因。

文件 SHA-256 在租户、组织和上传用户范围内用于重复文件复用。数据集、会话、问题和交易依据均使用平台提供的 tenantId、organizationId、userId 校验身份。安装范围为 tenant，业务数据按用户及组织隔离。

SQLite 保存原文件、交易、选择状态、会话、问答及处理阶段。事务、唯一约束、WAL 和忙等待用于保持并发一致性。持久化目录应位于本机可写磁盘。

## 统计规则

- 每行代表一笔成功人民币转账，付款账号指向收款账号，统计口径为账面收付款。
- 收款包括收款方位于所选账号集合中的交易，付款包括付款方位于集合中的交易。
- 净收支逐笔计算所选收款金额减去所选付款金额。集合内部互转对净额贡献为零，匹配笔数按唯一交易计算。
- 姓名用于检索，账号用于确认身份。同名多账号时等待用户选择。
- 金额使用整数分累加，传输与展示使用两位小数字符串。图表比例绘制使用数值。
- 时间统一为 Asia/Shanghai。上个月为自然月，上周为周一至周日。追问继承已保存的具体日期窗口。
- 自定义起止日期均包含当天，内部查询窗口为左闭右开。金额上下界默认包含边界，严格大于或小于由 minExclusive、maxExclusive 表达。
- 明细每页最多 50 条，排行最多 20 项，趋势最多 120 个分组，截断时显示提示。

## 工具与会话

| 工具 | 用途 |
| --- | --- |
| funds_query_context | 查询当前数据集、覆盖范围、时间和能力 |
| funds_query_find_accounts | 检索账号，识别同名歧义 |
| funds_query_run | 按受限条件计算并保存结果 |
| funds_query_result | 读取保存结果和分页依据 |

一个数据集可有多个独立会话。已绑定线程的会话先使用 assistant.chat.get_context 确认原生会话及就绪状态，按需使用 workbench.navigation.open 恢复。确认后创建带唯一 queryId 的问题，发送时携带目标会话及线程条件。

首次发送使用新线程，运行时由受信中间件上下文绑定真实 conversationId 和 threadId。同会话最近完成或待澄清的分析可作为 baseQueryId，模型根据问题选择继承条件或通过 clearFilters 清除条件。新会话从独立上下文开始。

线程绑定、继承和执行标识均由后台校验，首次线程绑定使用事务。早期缺少线程编号的会话通过近期历史摘要开始新的平台线程，后续保存并恢复该线程。

## 执行状态与错误

统计结果和最终文字回复分别保存。工具记录实际阶段，中间件捕获本轮模型最终文本，页面显示阶段提示与动画。结果先出现时可以核对依据并编辑草稿。

回执不确定时保留已保存的结果，并有界检查晚到回复。查询失败按状态显示恢复提示。导入校验失败保留行号诊断，后台刷新失败保留导入错误。导入请求中断时提示刷新确认数据集，再由用户重新选择文件。

## 验证与范围

模板递归限制为 100，最大输出预算为 16384。助手的实际模型参数以平台配置为准。统计完成后助手根据结果回复并结束本轮任务。

当前支持标准人民币交易的问数和证据核对。多跳资金归因、多币种、自动识别任意银行格式和会计核销属于后续扩展范围。

测试与验收分别见[验证结果](validation.mdx)和[完整测试流程](acceptance.mdx)。
