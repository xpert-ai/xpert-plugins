流水线视图 `material_identity_pipeline_overview` 面向治理负责人及有权限的角色用户，用于选择案例、查看各角色任务与推进下一步。案例状态、任务依赖和可执行节点均来自服务端投影。

## 信息层级

- 顶部工具栏只保留案例选择、当前状态、完成任务数和常用操作。案例标题只展示一次；过长时截断，完整标题可在“案例信息”中查看。
- “案例信息”使用 HoverCard 展示治理场景、源物料数、案例修订、流程版本、更新时间和 Mock 系统说明。鼠标悬停、键盘聚焦或点击均可打开，Escape 关闭。
- 协调者执行记录与画布缩放共用一行。画布操作说明按需展开，不再占用独立说明段落。
- 人工审批要求、阻塞原因及项目绑定失败仍直接显示，并保留相应处理入口，不藏在 HoverCard 中。

## Studio 布局与滚动

工作台填满宿主分配的高度，页面本身不滚动。流水线画布占用工具栏以下的全部剩余高度，横向和纵向滚动均在画布面板中进行。调整窗口或侧栏宽度时重新分配空间，无固定 420 像素最小画布高度，也不通过增加页面高度容纳全部泳道。

阶段表头在纵向滚动时固定于画布顶部；左上角“案例协同流水线”单元格同时固定于顶部和左侧。其余阶段表头随横向滚动移动，与对应任务列保持对齐。缩放后仍保留这些固定行为。

窗口变窄时，操作按钮分行排列，仍保留案例状态、进度及下一步操作。较长的上下文详情在 HoverCard 内滚动；治理监控和证据工作区的内容在各自内容面板中滚动。

## 交互与权限

1. 选择已有案例，服务端返回对应案例及流水线。刷新保留选择。
2. 点击角色助理卡片聚焦泳道；拖动画布空白区域平移，或使用面板滚动条、缩放按钮浏览。
3. 点击任务卡片进入该节点声明的详情或证据工作区。点击助理卡片、任务卡片或协调者区域的执行圆点，打开指定执行的规划记录与实际会话。
4. 点击“协调者推进下一步”仅调度当前有权执行的节点。待人工审批、已完成或无可执行节点时，该操作不可用。
5. 在证据工作区审查并批准方案后，返回流水线继续发布。布局调整不改变审批、修订检查或角色权限。

加载失败时显示错误及重试入口；无案例时显示创建入口；无选择时提示选择案例。上下文展开和缩放不触发业务写入，打开执行记录不替用户启动新的模型任务。

## 验收示例

- 已完成案例显示状态和任务完成数，下一步操作禁用；案例详情可展开。
- 待人工审批案例在画布上方显示审批要求，并可进入证据工作区。
- 在常见桌面和窄窗口中，外层页面无滚动条，画布底部保持在可视区域内。
- 切换案例、刷新、缩放或打开执行记录后，案例标识与执行归属保持一致。
