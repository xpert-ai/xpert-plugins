# AI 协作记录

使用 Codex 辅助理解 Xpert 示例、TypeScript 实现、测试及本地部署；运行时研究使用平台配置的通义千问 qwen3.8-flash。开发工具的具体底层模型未单独记录，不编造型号。

## 产品与边界选择

用户希望将原选股系统的影子实验拆出，作为面试要求的 Xpert 业务应用。最终选择冻结证据、独立任务、四阶段研究和人工确认；没有搬入私有评分、实时调度、交易和回测。保留财务缺失与弃选，避免用补造信息追求看似完整的结果。

## 代表性定位过程

- 通义连接持续 404：先核对接口协议，再读本机插件 URL 构造，发现表单 API Host 会自动追加 compatible-mode/v1。改为纯域名后连接可用。早期仅凭截图判断不充分，后续以实际实现为准。
- 工作台不显示：API 注册成功并不代表用户入口可用。检查已发布 graph 发现中间件节点和连接缺失，恢复后验证远程入口，再在浏览器通过“打开视图”显示工作台。
- 研究达到递归上限：真实工具调用已保存基本面，但预算 40 不足。调整为 120 并限制重复查证，随后实际记录四阶段完成与人工确认。提高预算不等于研究质量提高，仍需审阅证据。
- 快照大量未知：检查导出发现 20 只行情只有 5 条财务记录。保留缺失，并从原记录筛出 5 只证据较完整的演示样本，不用今天的数据填历史空白。

## 如何验证

分开记录业务测试、生命周期 Mock 加载、浏览器模拟宿主和真实平台模型执行；通过页面重入与 API 读取核对已确认记录。用户亲自完成最终确认并反馈刷新恢复正常。真实研究仍出现语义过度推断，因此不宣称投资准确率或自动化研究质量已完全验证。
