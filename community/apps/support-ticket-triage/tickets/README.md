# 工单分诊测试数据

此目录包含十条虚构工单，可用于在 Xpert 中检验模型分诊、人工审核和异常恢复。内容不含真实客户信息或凭据。

- 使用 `samples.json` 中的 `title` 和 `description` 创建单条工单。示例编号和 `expected` 供测试人员核对，避免在模型输入里附带答案。
- 对 TKT-001 可核对模型是否识别多人无法登录，并在人工审核保存后刷新页面，确认记录及调整后的内容仍可读。
- 对 TKT-008 可核对模型是否要求补充信息，同时避免生成未经证实的原因或者完成承诺。
- 失败重试可使用任意样例。临时模拟一次模型请求失败，然后重试同一工单，核对其工单编号保持不变且没有新增重复记录。

严重程度按业务影响判定。P0 表示核心流程全体阻断，P1 表示影响范围较大或金融风险需加急，P2 表示有限影响，P3 表示咨询或需求建议。示例中的预期用于验收，人工审核仍可根据上下文调整。
