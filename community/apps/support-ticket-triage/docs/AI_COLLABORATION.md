# AI 协作说明

## 使用方式

使用 Codex 阅读面试要求和 Xpert 当前公开仓库规范，先把题目压缩成一个可验证的小闭环，再生成插件源码、测试和交付材料。

## 关键选择

- 将大而泛的“智能客服”缩小为“工单分诊与回复草拟”。
- 用 Assistant 模型完成语义判断，用中间件工具保存结果，不在插件内绑定某一家模型 API。
- 引入人工确认状态，避免模型直接做退款等有业务后果的承诺。
- 把失败作为持久化业务状态，重试由显式状态机控制。
- 将平台未验证项明确保留，不生成虚假截图或虚构测试结果。

## 问题与处理

直接拉取 GitHub 仓库时网络连接失败，因此改为读取官方仓库的公开文件和当前开发 Skills，对照现有 Agentic App 的插件入口、Middleware、View Provider、Assistant 模板和工作区约定完成源码。由于缺少完整上游工作区依赖和 Xpert 测试实例，本轮只执行了不依赖平台的业务逻辑测试。

## 需要候选人掌握

候选人应能够解释状态机、租户隔离、Agent Tool 与 Workbench 的边界、为什么需要人工复核，以及平台实测后发现问题时如何从构建产物、插件加载、Assistant 模板和工具调用逐层定位。
