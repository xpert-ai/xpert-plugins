# 数据与隐私说明

本插件用于使用者自行部署的 Xpert 测试环境。以下说明插件自身的数据处理，不代表宿主、数据库或模型服务商的完整隐私政策。

## 收集与保存

插件保存使用者提交的原始反馈、补充内容、报告字段、追问及回答、人工修改保护标记、确认快照、版本和分析状态。分析尝试另外保存输入快照、源版本、结果、时间及有限错误码，便于失败恢复与过期结果保护。

记录关联平台可信上下文中的租户、组织和当前用户；分析任务还关联助手、工作空间与尝试标识。插件不要求用户额外提供邮箱、手机号或设备标识，但自由文本本身可能包含用户输入的个人或业务信息。

数据存放在宿主 PostgreSQL 中。用户通过平台登录与授权访问，插件按租户、组织、记录所有者限制查询和修改；管理员也不能通过本插件接口读取其他所有者的记录。该说明不承诺数据库管理员或宿主运营者无法访问底层存储。

## 模型与网络

只有在点击整理、重试，或请求助手调用分析工具时，插件才为对应记录发起分析。原文、补充、人工字段及已保存回答经平台模型运行时发送至使用者配置的模型服务。聊天请求由宿主助手及其已配置主模型处理。

模型连接与凭证由宿主管理；插件不读取 API key，不把密钥放进任务负载、模板或页面。队列负载只包含分析尝试 ID。远程界面从插件产物加载，不从第三方 CDN 拉取运行时，也不使用浏览器 Web Storage 保存业务记录。

插件没有自行增加广告、统计或独立遥测服务。实际网络与日志策略仍受宿主和选定模型服务商影响；部署者应按自己的使用场景配置这些服务。

## 日志与保留

插件只向页面返回有限的业务错误码，不返回原始模型传输错误、SQL 或堆栈。调试日志默认关闭，启用时只记录受限的事件状态与计数，不主动打印反馈全文或凭证。

业务记录与分析尝试没有自动到期删除逻辑，也暂未提供删除界面。队列作业的清理策略为成功或失败后保留至多 24 小时、每类至多 500 个；这不会删除 PostgreSQL 中的报告或分析尝试。宿主缓存、日志与模型服务商的保留规则应分别管理。

如需清理测试材料，应由部署管理员按宿主数据管理和备份策略操作。确认报告保留独立快照，并不表示其内容自动脱敏。演示与仓库截图使用明确标记的虚构材料；测试账号密码、实例标识和原始运行回执不随代码提交。
