## 一张订单怎样打开 24 张工作单

销售、工程、计划、制造和售后围绕同一张 12 台 EM-160 订单工作。采购员首先要知道密封组件少几套、最早哪天到；质量负责人首先要知道检验报告涵盖哪批产品、放行后谁会收到通知。把同一组“输入 / 输出”字段复制给两个岗位，会掩盖他们各自承担的决定。

采用现有订单工作台 View。上方保留订单号、工厂样例模式、提取规则版本和原生项目入口。第一层选业务阶段，第二层是该阶段的节点 Tab。进入在办订单时定位当前节点；并行期间两个岗位分别可见。每页显示本节点负责岗位、工作单、上游凭证和下游接手岗位。节点之间可直接跳转，审批意见只归属正在操作的订单与节点。

原生泳道中，单击节点先打开详情。例如，在质量助手中点击「检查齐套与在途物料」可查看该节点的执行记录与证据。再点「打开节点工作台」，会按该次运行的绑定切换到采购齐套助手，打开同一订单、同一轮次的「物料齐套」Tab。人工审批、流程判断和审批回执在订单协调助手中查看，审批权由对应人工节点决定。

V1.1 有 18 个业务节点（13 个智能体任务、5 道人工审批）、4 个逻辑节点和 2 个终点，共 24 张主工作单。5 道审批各有批准、退回两个回执子页，覆盖原生定义中的全部 34 个节点。旧单按 V1.0 的 14 个业务节点展示。管理层仍从订单总览比较订单，流程运维仍从原生泳道查看运行状态与执行记录。

## 业务依据与界面取舍

- 物料须按需求日核可用量。把在库、在途、供应商确认到货日和缺口分开，才能解释为何要核期，以及提前三天的交付是否能兑现。电机样例只计算单个密封件的数量缺口；客户上线需补库存预留、质检冻结量和需求日 ATP 口径。[SAP 生产订单物料可用性检查](https://help.sap.com/docs/SAP_S4HANA_CLOUD/2bba750d1e124e1ea2a039bb1cd9b6c5/e9f1c0b7a068415b9359e3023d3cc9d6.html?locale=en-US)
- 检验结果、批次使用决定和仓储动作有各自的责任人。试验节点保留报告，质量节点决定批次能否交付，仓储节点登记出库与签收。客户可把其检验特性、样本评定和处置码映射到这三步。[SAP 检验批使用决策](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/2bc3ee8d1c83404e8cf62418640004f2/3a7fb6535fe6b74ce10000000a174cb4.html)
- 售后根因和改进验证需要独立证据。报修描述、拆检发现、纠正措施和复发观察窗口分开呈现。样例首批 12 台中有 1 台报修，改进批次尚无在役分母；六条条款的回放命中率衡量的是合同提取能力。[AIAG 汽车质保管理术语](https://www.aiag.org/docs/default-source/quality/aiag-cqi-14-warranty-key-terms.pdf)

## 各岗位打开什么、决定什么

| 阶段与节点 | 负责方 | 专属工作单与关键核对 | 动作、输出与接手方 |
| --- | --- | --- | --- |
| 接单 · 合同评审 | 销售需求助手 | 合同行和 §4.2 原文并读，分别提取总成与端子盒等级，显示交付数量及规则来源 | 保存要求摘要，交 BOM 工程助手；衍生单可追到原订单 |
| 工程 · BOM 差异 | BOM 工程助手 | 单台变更对照。总成 IP54→IP67，端子盒维持 IP54，紧固件 4→8，新增密封组件 | 提交差异与试验要求，交工程负责人 |
| 工程 · 版本冻结 | 工程负责人 | 同屏查看差异单、整单展开和拟冻结修订。12 台需要 96 件紧固件、12 套密封件 | 核准后采购按 B 版齐套；退回登记依据，结束本单 |
| 排程 · 物料齐套 | 采购齐套助手 | 从冻结 BOM 核对物料编码、需求、现存、在途和改后交期 | 留存数量快照，交齐套 Router |
| 排程 · 齐套判断 | Router | 对照本单需要量与可用量，显示两条出口及选中情况 | 缺料进入供应商核期；齐套直接交计划助手 |
| 排程 · 供应商核期 | 采购齐套助手 | 查看 4 套缺口，常规第 10 天到、加急第 7 天到，额外费用 960 元，台架还需 2 天 | 转交有依据的交期与成本；采购下单属于后续客户系统动作 |
| 排程 · 方案测算 | 生产计划助手 | 三方案横表比较首批数量、首批日、齐交日、加费和被挤占工单 | 交计划负责人选案，保留其他选项供比较 |
| 排程 · 排程决策 | 计划负责人 | 查看三方案、供应商回函和工单 22B 的影响；展示本单签署的方案 | 整批提前、分批、维持原计划或退回。选分批则第 9 天交 8 台、第 12 天交 4 台 |
| 生产 · 实装登记 | 制造交付助手 | 工单串起冻结版本、实装密封批次、首台序列号和报产回执 | 保存实装台账，质量助手按序列号查试验 |
| 生产 · 出厂试验 | 质量与验证助手 | 受检序列号、台架记录、报告号、首检数量；衍生单另列密封圈定位复核凭证 | 交质量负责人判定放行 |
| 生产 · 质量放行 | 质量负责人 | 放行签核单上核对批次、报告适用范围与数量，保留审签依据 | 批准后制造交付助手可发运；退回保留判定记录 |
| 生产 · 交付签收 | 制造交付助手 | 联查批准的交期、质量放行、出库单、首台序列号及签收凭证 | 按实际批次登记签收，售后可按实物反查 |
| 售后 · 报修受理 | 售后改进助手 | 从签收锁定报修电机，分别记录“雨后报警、疑似进水”和拆检发现 | 提交服务单，触发两路取证 |
| 售后 · 并行派发 | Fork | 一份报修序列号，两张取证任务，显示各自负责人 | 制造助手查 MES；质量助手查 QMS，两个结果可先后到达 |
| 售后 · MES 实装 | 制造交付助手 | 从首台序列号回查实装密封件批次、BOM 修订；可打开原工单凭证 | 向汇合节点提交实装查询回执 |
| 售后 · QMS 索引 | 质量与验证助手 | 查看索引查询键、返回的受检序列号及报告号，未命中明确登记 | 向汇合节点提交命中或未命中回执 |
| 售后 · 证据汇合 | Join | 两个来源各占一栏，分别显示执行状态与查询结果 | 两份回执都到齐才核验。未命中也表示查询已完成 |
| 售后 · 序列号核验 | Router | 并排读实装序列号、报告序列号与报告号，并查看实际出口 | 匹配送根因签核；缺索引或不匹配则补证 |
| 售后 · 归档补证 | 质量与验证助手 | 按工单找出厂原件，对照原件号和序列号，再回看为何触发补证 | 核验原件后提交根因审批；客户系统若无原件，应进入异常处置 |
| 售后 · 根因与措施 | 质量负责人 | 并读客户现象、样件拆检、实装批次、试验报告。候选措施为密封圈定位复核并留存照片 | 确认根因、工程措施及 90 天观察窗口，交工程助手回放 |
| 售后 · 专家回放 | BOM 工程助手 | 逐条比对专家标注、R1、R2，包含只出现部件等级及信息不足的样本 | 将六条样本及回放结果提交工程知识负责人 |
| 售后 · 规则发布 | 工程知识负责人 | 核对评估、版本影响范围、已批准的装配措施；可查 Agent Evolution 回执 | 发布后完成项目审批，新衍生订单冻结 R2，并继承本单措施 |
| 终点 · 结案 | 流水线引擎／订单协调人 | 从结案页打开发布依据，核对本单采用的版本和下一单继承范围 | 从已完成订单创建下一单，查看监管链及 BOM 新增复核 |
| 终点 · 退回 | 流水线引擎／原审批岗位 | 显示作出退回决定的关口、账号、时间与依据 | 本轮结束；演示中不自动退回某个上游重做 |

## 从一单走到下一单

1. 在缺料样例打开「插单排程 → 供应商核期」，先看第 7 天到货，再看方案测算如何把 2 天试验时间算入第 9 天交付。打开排程决策，选择分批并写明接受加费的理由，完成后查批准回执。
2. 换到齐套且缺索引的样例。供应商核期显示本单跳过。在「售后改进 → 证据汇合」查看 MES 已找到实装批次、QMS 已完成查询但未命中；打开序列号核验查看路由，再到归档补证核对原件。
3. 根因确认后，查看回放中“端子盒 IP54；总成 IP67”一行。进入规则发布和结案，从已完成的订单创建下一单，在合同评审确认总成提取 IP67，在新单 BOM 查看继承的装配要求。后续在役效果由售后台账持续观察。

## 展示、写入与客户对接边界

样例演练用同一业务服务校验顺序、决策人、审批理由与选案。节点未执行时可查已到达的上游凭证；待审材料以样例标识。跳过的节点无执行回执。原生流水线读取已授权项目的图、节点 ID、实际选中边与回执数量，业务审批从工作单打开对应的原生节点，执行记录进入对应 Assistant 的会话。从历史轮次进入时，工作台只读展示该轮的节点状态和证据数量，可返回原生节点查看详情。技术回执在五个签核页内按批准和退回拆分查看。

五组审批回执默认收在各自的审批节点下。在「阶段泳道」点击「展开审批后续步骤」，单击「记录批准结果」或「记录退回原因」可查看该次回执详情。再点「打开节点工作台」可进入该次签核的对应子页。工作单上的「打开原生节点」可返回执行详情。待处理节点显示「在项目中处理」，负责人可在原生界面核对材料并提交决定。

客户上线时优先对齐四组关联键。合同版本与订单行连接 CRM、ERP 和 PLM；BOM 修订、料号及需求日连接 PLM、ERP、WMS 与 APS；工单、序列号、实装批次连接 MES 与 QMS；服务单、失效件序列号、纠正措施版本连接售后、工程与知识治理。原件存储、电子签名、按岗位分权、正式写回和回执对账需要客户授权接口。样例中一个订单负责人可以扮演多个签核岗位。
