---
title: 样例数据与工厂系统
description: 用同一订单行、技术版本和实物序列号连接各系统
---

| 业务对象 | 演示中可见 | 对接客户系统时补充 |
| --- | --- | --- |
| 合同和订单行 | 条款原文、总成要求、来源订单、提取规则 | CRM 或 ERP 的合同版本、订单事件与授权账号 |
| 技术 BOM | 防护等级、用量变化、批准人与冻结修订 | PLM 的变更单、签审状态、生效版本 |
| 物料和排程 | 在库、在途、欠料、插单影响、人工选案、计划回执 | ERP / WMS 库存可用量与供应承诺；APS 日历和产能约束 |
| 生产和质量 | 工单、密封件批次、实装序列号、试验和放行回执 | MES 报工与装配实绩、QMS 检验报告及放行权限 |
| 交付和在役 | 出库、分批签收、报修、拆检及工程措施 | WMS 出库及签收接口、售后系统的服务记录、在役观察分母 |
| 经验和下一单 | 审批过的工程措施、六条历史回放、版本回执、后续采用证据 | 工艺变更会签、经验卡归档与跨订单推广范围 |

blueprints/motor-ontology-v1.json 提供 Data Xpert 定义草案与中性样例。主链从订单、订单行、BOM 和工单到出厂电机；从电机可追溯密封批次、试验及签收，从售后工单可反查实物和措施。后续订单关联措施和规则。每个现场演练使用自己的样例和回执。连接真实本体资源、映射接口与写回均需在客户环境单独实施。
