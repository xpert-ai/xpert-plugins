- 插件已在本地 Xpert 加载，Assistant 模板已安装并发布，Workbench 可从 Assistant 打开。
- 租户级和组织级主模型均为 DeepSeek `deepseek-v4-flash`，两者作用域分别验证。
- 一次真实模型调用完成 `meeting_begin_extraction`、1 次 `meeting_upsert_decision`、2 次 `meeting_upsert_action_item` 和 `meeting_finalize_extraction`。
- 合成样例生成 1 条决议和 2 条行动项；信息不足的行动项截止日期为 `null`，没有猜测。
- 刷新后的 Workbench 能从 PostgreSQL 恢复会议原文、证据和提取结果。
- 插件 0.3.0 已刷新到本地平台并在重启后注册；部署描述符版本为 0.3.0、`loadStatus` 为 `loaded`，API readiness 返回 `ready`。
- 现有 Assistant 保留原 ID、名称、会话和绑定并同步模板 v4；Agent 与 Middleware 工件哈希均升级到 v2。同步未创建新的发布版本，因此平台仍显示 v1。
