## 处理的数据

应用处理用户主动输入的会议标题、会议原文，以及从原文生成的决议、行动项、证据、置信度、风险和跟进简报。会议原文可能包含姓名、职责或其他由用户提供的组织信息；应用不会主动采集邮箱、IP 地址、浏览历史、设备信息或支付信息。

## 处理目的

数据只用于完成会议内容提取、人工复核、行动项跟踪、执行风险巡检和下次会议简报。应用不把这些数据用于广告、用户画像或训练本插件自有模型。

## 模型传输

当用户主动发起 AI 提取或 Agent 执行巡检时，完成任务所需的会议上下文会通过 Xpert 已配置的模型提供商发送。具体提供商、区域、保留策略和服务条款由 Xpert 管理员选择的模型服务决定。用户应优先使用合成、脱敏或已获授权的数据。

## 存储和隔离

会议、决议、行动项、执行巡检、风险信号和操作回执保存在 Xpert 使用的 PostgreSQL 中。所有读写都按 `tenantId` 与 `organizationId` 限定；Remote View 不使用 `localStorage` 或 `sessionStorage` 保存业务数据。

## 凭证和日志

插件不接收或保存模型 API Key。密钥由 Xpert 平台的模型提供商配置管理。日志只记录必要的生命周期和脱敏错误，不记录密钥、Token、完整会议原文、完整工具输出或内部堆栈到用户界面。

## 删除和保留

当前版本没有独立的数据保留策略或自助批量删除界面。数据保留和数据库备份遵循部署方的 Xpert/PostgreSQL 运维策略；如需删除，应由有权限的管理员按照部署方流程处理。后续版本应补充应用内删除与审计能力。

## 用户责任

用户在输入会议内容前，应确认自己有权处理并向所选模型提供商发送这些信息。对于真实业务数据，建议先删除不必要的个人信息、访问凭证、客户秘密和其他敏感内容。
