# 放简历的地方

## 怎么放

每个候选人的简历放成一个文件，文件名就是候选人标识：

```
demo/resumes/张三.txt
demo/resumes/李四.md
```

支持 `.txt` 和 `.md`。文件名（去掉后缀）会作为 `sourceName` 传给模型，
用来在结果里区分候选人。

脚本会读取目录下所有 `.txt` / `.md` 文件，按文件名排序逐个分析，
所以放几份都行，不限于两份。

## 内容要求

**必须是文本**。`.docx`、`.pdf` 需要你自己先转成纯文本再放进来，
扫描版 PDF 转出来是空的或者乱码，跑出来结果没意义。

一份起码要有：工作经历（公司、时间、职责）+ 技能。

## 隐私提醒

简历是真实个人信息。`.gitignore` 里已经把这些文件排除掉了，
但上传、分享、截图之前还是自己确认一遍。
