## 已知限制

1. 真实模型调用、助手在平台内创建/绑定、浏览器端到端流程与生命周期 harness 均**尚未执行**，不能声称业务已跑通。本会话只保证逻辑单测、跨 SDK 编译与产物构建。
2. AI 只写草稿、不代用户确认/删除；这是有意的边界设计，代价是"AI 直接落库最终用例"不成立。
3. 界面为 iframe 远程组件，依赖宿主 `append_references` 客户端命令把需求带入聊天；若宿主该命令不可用，"AI 生成"入口会失败，需降级为手动粘贴引用（未实现降级，记为缺口）。
4. 单需求单工作空间视角优先；多需求批量、编辑既有确认用例的字段级表单、外部用例库导出未做。
5. 数据以单条 JSON 文档 + 单 `revision` 乐观并发；高并发同文档写会频繁冲突（本范围可接受）。
