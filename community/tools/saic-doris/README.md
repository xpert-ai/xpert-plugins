# @xpert-ai/plugin-saic-doris

SAIC 供应链六张配置表的 15 个读取工具、9 个写入工具，以及 `schema://saic/config-tables` 资源。工具名称、参数和业务返回结构对照原 Python MCP 服务；安全修正见兼容说明。

在平台数字专家中添加 **SAIC Doris 中间件**，即可直接使用全部 24 个工具；通过 Xpert 原生 MCP Publication，可向 WorkBuddy 等客户端提供相同工具的 Streamable HTTP 接口。每个中间件或 MCP 工具集独立选择有权限的**平台 Doris 数据源**，或**手填 Doris 连接**。连接信息不进入工具参数。

插件保留 SDK 默认的普通工具集注册，并通过 `.xpertai-plugin/plugin.json` 声明原生 MCP 资源，兼容宿主现有安装路径。数字专家使用中间件；外部 MCP 复用工具集适配器和相同的 24 个方法。现有连接和 Publication 无需删除重建。

## 平台数字专家使用

推荐使用插件附带的 **SAIC 供应链配置助手** 模板：打开**创建专家 → 智能体 → 模板**，搜索 `SAIC`，选择模板、目标工作空间和名称，点击**安装并发布**。打开创建的专家，在编辑器中确认支持工具调用的模型，再配置 **SAIC Doris** 中间件连接并重新发布。模板已连接对话触发器与中间件，提供任务巡检、字典校验、配置更新和写后核验说明及四个起始问题。

模板不携带数据库地址、密码、数据源 ID 或固定模型；宿主可以使用当前组织的默认模型，数据库连接仍须在创建后配置。安装完成不代表连接已就绪。它不会自动建表、发送邮件或启动采集任务。若已有数字专家，也可直接添加中间件：

模板参考 ClawXpert 保留上下文压缩、循环保护、模型重试和工具消息修复，无需沙箱，不预置待办事项、网页检索、文件、图片和技能中间件。数据库读写仍限定在 SAIC 工具内。升级模板不会改写已经创建的专家；旧模板创建的专家需要手动移除待办事项和网页检索中间件（若启用了沙箱，还需关闭沙箱并移除文件、图片和技能中间件），或从新模板创建。

1. 安装 MySQL/Doris 数据源插件和 SAIC Doris 插件。
2. 打开数字专家编辑器，选择智能体节点，在**中间件**中添加 **SAIC Doris**。
3. 在中间件配置中选择平台数据源，或填写手动连接；保存数字专家。
4. 在调试对话中要求“调用 ping 检查 Doris 连接，再调用 list_config_tables 列出配置表”。随后可按业务需要查询或更新六张配置表。

此入口无需启用 MCP 服务或填写 MCP 地址。中间件配置只作用于当前智能体，独立于 MCP 工具集连接。平台模式每次调用都检查当前执行用户的数据源权限。升级插件会更新可选模板，不会自动覆盖已有数字专家的提示词、模型或连接。

需要支持原生 MCP 与 DataSource Runtime Capability 的 Xpert 宿主、SDK `^3.21.0`，以及本次新增 Doris 公开入口的 `@xpert-ai/plugin-mysql`。支持 MCP 插件页签的宿主中，打开 **MCP 管理 → 当前服务 → 配置连接**，即可编辑已有连接；旧宿主仍可使用原有管理接口，见 [MCP 接入](docs/mcp.mdx)。不依赖普通工具集注册拆分或独立连接弹窗。平台数据源模式需要宿主正确加载 MCP 用户角色权限；编辑器单工具测试需要组织上下文。两个插件需配套构建/发版；已有 0.1.0 驱动不包含新入口。SAIC 构建会从正式的 `@xpert-ai/plugin-mysql/doris` 入口打包共享驱动，避免宿主的 npm 工作区安装遇到 `workspace:` 协议或解析到已发布的旧驱动；平台模式仍使用已安装的数据源插件。业务表、主键模型和访问授权须预先存在。

开发时从仓库的 `community/` 目录按其 `packageManager` 安装依赖，先构建驱动，再构建本插件。详见验证文档。文档由 Mintlify CLI 初始化；不需要额外启动 MCP 子进程。
