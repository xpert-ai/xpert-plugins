SAIC Doris 将供应链配置表接口作为一个原生 Xpert Tool Provider 注册。业务服务提供 24 个工具和一个 schema 资源，Xpert 负责 MCP Publication、鉴权和管理员审批策略。

## 数据范围

仅允许 `sc_task`、`sc_part_cross_ref`、`sc_owner`、`sc_ship_rule`、`sc_run_log`、`sc_agent_run`。不提供 `sc_credential` 访问、建表、授权管理或自由写 SQL。

## 连接和执行

- 平台模式：通过 `DataSourceRuntimeCapability.list/open` 选择并打开有权限的 Doris 数据源，凭据保留在平台。
- 手填模式：调用 `@xpert-ai/plugin-mysql/doris` 公开工厂创建同类适配器。
- 每次工具或资源调用读取当前工具集配置，创建独立连接，执行完毕后释放。数据库时间缓存只存在于本次连接实例。
- 服务共享字段校验、读后合并写入、查询计数、哈希与状态回写逻辑。连接方式不改变工具参数。

从[连接配置](/configuration)开始，再配置[MCP 接入](/mcp)。完整行为见[工具契约](/contracts)及[兼容说明](/compatibility)。
