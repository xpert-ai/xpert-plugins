## 行字段与主键

通过 describe_config_table 获取当前数据库列类型。以下为写入校验必填列；所有可选列、最大字符长度与类型见插件 `src/lib/tables.ts` 中 COLSPEC。未知列拒绝。

| 表 | 主键 | 必填列 |
| --- | --- | --- |
| sc_part_cross_ref | customer_part_no | customer_part_no |
| sc_owner | owner_name | owner_name, email |
| sc_ship_rule | factory_code, source_tag | factory_code, source_tag, offset_days |
| sc_task | seq_no | seq_no, task_code, task_name, site_code, spec_text |
| sc_run_log | run_date, task_seq | run_date, task_seq |
| sc_agent_run | run_id | run_id, triggered_by |

任务/Agent 状态集合：`idle`、`queued`、`running`、`need_info`、`done`、`failed`。insert_run_log 与 insert_agent_run 保留原始状态写入行为，不额外套用更新接口的状态枚举校验。

## Schema 资源

`schema://saic/config-tables` 返回 JSON 数组，每项包含 TABLE_NAME、TABLE_COMMENT、columns。通过固定 information_schema 查询限定当前数据库及六张表，上限 50。资源没有调用参数，不缓存跨连接结果。

## 错误约定

空数组、未知列、缺必填列、批量超限、无更新字段、重复任务主键/标签、缺失记录或无效状态返回原业务 error 对象。数据库执行、权限和配置异常属于执行错误。安全拒绝及边界差异见[兼容说明](/compatibility)。
