---
title: '测试与验收'
description: '协议测试与 xpert-pro 本地闭环。'
---

单元测试使用真实 CSV、JSON、XLSX 字节及实际 Worker 入口，覆盖精确求和、筛选、源文件替换、保存后的 Binding 重用、输出类型、权限撤销、目录隔离、非法路径、取消、结构变化、公式、压缩包大小限制、伪造 ZIP 大小及流式/未压缩 ZIP 的兼容性。构建后运行仓库插件生命周期测试，确认产物可以加载。

本地验收需要在已发布测试 Assistant 的文件工作区配置三种等价来源，通过真实 Chat 一句话生成看板，核对已知总额与明细，切换筛选，通过 Files 更新源文件后刷新，关闭/重开资源卡片并刷新宿主页面。确认 Artifact 和 Binding 保留，取数使用更新后的文件。

撤销当前访问者的来源或文件权限后，发现与已保存查询都应失败；恢复后重新取数。另验证未知 Binding、额外控件、文件或 payload 覆盖、浏览器直接请求后端和访问父 DOM 均不能绕过边界。

机器路径、账号和验收资源 ID 只保存在本地回执中。协议测试、加载成功和本地应用验收是不同层次，本批不进行正式发布验证。
