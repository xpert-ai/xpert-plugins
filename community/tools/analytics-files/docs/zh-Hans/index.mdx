`file.table` 让 Agent 直接发现已配置的文件数据集，通过字段选择、筛选、聚合和排序生成看板。管理员明确文件、字段类型及业务口径；Agent 使用真实预览结果构建 Binding。无需新增 Agent 中间件。

平台负责文件访问、当前访问者权限、Dataset/Binding、查询限制及 Artifact 生命周期；本插件负责格式解析、查询语义、类型转换与精确聚合。看板插件继续使用原有标准图表和 HTML/JS 渲染。

每次筛选和刷新重新读取文件，查询结果携带文件摘要。保存 Artifact 固定查询定义，不冻结业务数据。替换文件但保留字段契约后可直接刷新；删除字段、改变类型或修改数据源定义会要求修正文件或重新发现、预览。

首期限制：输入最多 8 MB、50,000 行，返回最多服从平台行数上限（当前 1,000 行）、2 MB。超出输入限制直接失败，不对部分输入计算“完整总额”。返回行数被截断时保留完整性标记。

解析和聚合在可终止 Worker 中执行，服从平台截止时间。XLSX 限制解压总量 40 MB、2,000 个 ZIP 条目及 200 列。解析工作簿前先检查 ZIP 声明大小，再分块计数实际解压字节；大小不一致直接拒绝。拒绝宏、外部工作簿内容、隐藏工作表和合并的数据单元格。默认拒绝公式；显式选择缓存模式仅使用文件内已有结果，不计算公式，也不保证缓存最新。
