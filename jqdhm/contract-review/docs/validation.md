## 本地真实模型验证

通过 `npm run demo` 启动 Java 的 `local-extraction` 配置和本地预览页，再执行 `node scripts/verify-local.mjs`。验证使用 `examples/contract.txt` 中的虚构合同，走的是预览接口 → Java → 本机 Ollama → Java 数据库的真实链路。

六个候选字段均包含可在原文中逐字找到的依据；标题与正文保持调用者输入。首次提取生成 DRAFT v1，保存后为 v2，人工确认后为 CONFIRMED v3。重复提取返回同一记录，确认后的提取重试也不会覆盖已核对结果。用旧版本保存会被拒绝，重复确认不会新增审计记录。

本次验证时间为北京时间 2026-09-21 22:06。机器上的模型为 `qwen2.5:7b`，该示例用时约 12.4 秒；这个耗时只反映本次短合同验证，不代表长合同或并发性能承诺。非敏感的运行记录位于本机 `test-results/local-ollama-flow.json`，该目录不提交到 Git。
