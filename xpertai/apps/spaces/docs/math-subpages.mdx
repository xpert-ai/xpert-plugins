## 产品行为

顶部插入菜单新增「数学公式」与「子页面」。编辑器仍保持单文档布局，生成与审阅继续由 Assistant 承担。

公式弹窗包含独立公式块/行内样式、LaTeX 输入、实时预览与错误提示。点击已有公式可以修改或删除；只读成员可以查看源码。新公式插在当前块下方，保留原选区；行内样式放在一个新段落中，也可以在正文通过 `$…$` 输入。代码块内的公式源码保持原文。

创建子页面时输入名称，保存当前文档后创建并在同一 Workbench 打开。子页面上方显示返回父页面入口，父页面正文下方显示子页面列表与创建入口，不增加空间侧边菜单。列表可刷新，以获取其他成员新建的页面。

## 文件与层级

- 每个子页面是独立 `.md` 文件、内容资源和协作文档，保存到创建时父页面所在的项目文件夹。文件名采用「名称--资源 UUID.md」，避免同名覆盖；显示标题不带 UUID。
- `SpaceItem.parentId` 继续代表文件夹；新增 `parentPageId` 记录逻辑父页面，`childRequestTitle` 记录原创建请求。正文仍保存在项目文件中，知识库继续作为检索索引。
- 父子关系不是权限继承。所有用户和 Assistant 都必须通过当前项目和资源授权。
- 父页面改名、移动不改写子页面身份或文件位置；移动整个文件夹仍按文件夹规则处理其中的文件。
- 删除父页面不级联删除子文件。父页面不可访问时，子页面隐藏父入口，仍能从协作空间打开；恢复父页面后重新显示关系。单独删除子页面会从父列表隐藏，恢复后重新出现。
- 新建层级最多 32 层，每次展示前 100 个直接子页面。当前不提供重新挂接父页面或子树复制功能。
- 页面层级属于 Space 元数据，单独下载 Markdown 不包含层级关系；可用「页面引用」在正文中加入可导出的链接。

## 公式持久化与协作

前后端共用 Tiptap Mathematics 节点：`inlineMath`、`blockMath`。行内保存为 `$LaTeX$`，独立块保存为单独两行 `$$` 包围的 LaTeX。渲染采用 KaTeX，字体随插件打包，不依赖 CDN。

每条公式具有稳定 `mathId`；独立公式另有 `blockId`，支持 Assistant 精确提案。弹窗保存前按 ID 重新定位并核对原 LaTeX，发现协作者已修改/删除时拒绝覆盖。实时并发合并沿用 Yjs；普通正文中的复杂行内节点仍不能用纯文本提案粗暴替换。

schema 升级到 v3，沿用已有显式升级机制，支持 v1/v2 无损升级：保留原 CRDT、文件字节、块 ID 和历史，发布新 epoch 隔离旧客户端。既有普通文本不会因升级被自动转换成公式。

单条公式最多 4096 字符，每文档最多 200 条。输入不含外层 `$` 分隔符，行内源码不换行。只支持 KaTeX 的 LaTeX 子集；不执行外部命令，不信任 HTML/URL 指令，限制宏展开和渲染尺寸。语法错误会提示并阻止提交。

## 插件与平台边界

Markdown 仅调用平台 `document.hierarchy` / `document.createChild` 视图动作。平台校验身份、项目和来源资源，将层级查询/创建委托给来源 Provider 的可选 `pageHierarchy` / `createChildPage` 扩展点。未实现此能力的来源不展示子页面创建入口。

Spaces 实现自己的逻辑层级与文件创建。平台复核返回的新资源仍属于当前项目；前端经 `workbench.content.resolve` → `workbench.navigation.open` 打开，不逃逸到外层 Workbench。

创建请求携带固定 UUID。同一个用户、父页面、标题与请求 ID 重试只会继续原创建；不同载荷复用 ID 被拒绝。已写入文件但发布失败时保留创建意图，重试前检查文件哈希，绝不覆盖外部修改。

## 部署与验证

平台 SDK、平台服务、Spaces 和 Markdown 插件须一起更新；生产数据库先执行 `migrations/20261023-subpages.sql`。开发环境可使用宿主实体同步。刷新已打开的编辑器以声明 schema v3；只读成员不能代替写权限成员升级旧文档。

已完成本地部署与验收（2026-10-23）：

- Markdown 19、Spaces 22、平台文档/层级/升级 14，共 55 项定向测试通过；两个插件的类型检查、构建、元数据及生命周期加载检查通过。
- 5 项真实接口场景通过：公式导入不改原文件、并发重试不重复创建、多 Assistant 共享与越权拒绝、父页面改名/回收/恢复、公式 CRDT 修改物化到文件。
- 浏览器实测：无效公式阻止保存，行内公式编辑，独立公式预览和插入，子页面创建/编辑/返回父页面，刷新后内容与层级保留。新子页面在当前 ChatKit Workbench 内打开。
- 服务重启后核对父/子页面的实际 Markdown 文件、内容与哈希一致。已有 v2 文档升级到 v3 后正文和块 ID 不变，旧 schema 客户端请求被拒绝。
- 本次属于定向验证，未完成平台全库测试；扩展测试范围时遇到既有 `agent-execution.service.ts` 的 TS2589 类型实例化错误，未计为通过。生产发布和跨节点部署不在本次本地验收范围。

可重复运行的接口验收脚本为 Markdown 插件 `tests/math-subpages.live.mjs`，通过 `SPACES_TEST_DIRECTORY` 引用私有测试环境，正常登录后执行；脚本会创建验收页面。凭据与部署 ID 不写入插件文档。
