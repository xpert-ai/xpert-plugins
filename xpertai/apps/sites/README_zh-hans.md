# 站点

站点是独立安装的 Xpert Agentic App：在左侧现有会话中生成和迭代静态网站，在右侧插件视图中预览、保存版本、确认发布和恢复草稿。界面使用仓库本地 Shadcn UI + Tailwind，并继承宿主主题。

## 使用流程

1. 安装并初始化应用，复用组织现有的模型配置。
2. 进入站点助手，在右侧新建站点并描述需求。请求发送到现有会话。
3. 助手在当前沙箱工作目录的 `sites/<slug>/` 中生成 HTML、CSS、JavaScript 和本地资源，保存不可变版本。
4. 在右侧预览，切换桌面或手机宽度；通过「继续修改」在左侧迭代。
5. 点击发布，确认具体版本和可见范围。仅自己、工作空间、指定用户或公开链接由 Xpert Artifacts 授权。
6. 恢复历史版本会创建新草稿，已发布版本保持不变；重新发布需要再次确认。

## 能力边界

当前支持静态、可自包含的单页网站。本地 CSS、JavaScript 模块、图片和字体会打包进产物。预览采用不透明来源 iframe 和 CSP 隔离，不能读取宿主会话、浏览器存储或调用网络 API。当前不提供 D1/R2、服务端路由、自定义域名、用户认证或真实流量分析。

环境变量仍可经中间件管理，静态页面不注入密钥。秘密值需要配置 `environmentEncryptionKey` 后加密存储，视图不返回秘密内容。

## 开发与验收

先构建仓库本地 `@xpert-ai/plugin-shadcn-ui`，再运行插件的 Nx typecheck、build、test 和 verify:dist。生命周期验证使用 plugin-dev-harness，workspace 指向本插件目录。安装后必须在真实宿主验证：创建、模型生成、预览、确认发布、恢复草稿、权限和刷新恢复。

嵌入式 ChatKit 的选择与标签恢复依赖宿主导航持久化；插件 iframe 不访问 localStorage/sessionStorage。
