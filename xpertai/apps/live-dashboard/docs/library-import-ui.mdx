---
title: ZIP 导入交互组件
description: 资源包检查、确认导入及任务恢复
---

<Warning>
此组件处于 Beta 阶段，交互、宿主 Action 和任务状态约定可能发生破坏性调整。
</Warning>

`ResourceImport` 为资源目录提供可复用的导入对话框，通过 View Bridge 调用已有的资源包导入能力。使用共享 shadcn 组件，文案覆盖英文、简体中文和繁体中文。

1. 选择处理方式：复用内容相同的版本，或创建独立副本。
2. 上传 ZIP 后展示资源名称、版本以及新建、复用或冲突的检查结果；上传本身不提交导入。
3. 用户确认后提交任务。存在内容冲突时禁用确认按钮；导入中的任务不能重复提交或取消。
4. 可查询任务状态、重试失败任务，或取消尚未运行的任务。已完成和已取消的任务不再提供提交操作。
5. 再次打开对话框时查询最近任务，选择任务后继续查看处理进度。

客户端在上传前检查文件大小和当前 View 作用域。服务端仍负责完整的 ZIP 校验、权限检查、幂等性与持久化；导入得到私有资源，不会自动公开。

本批提供独立组件及文案，目录页面的入口接入随后单独审核。模板清单、任务提示词、示例数据和封面不包含在本批中；此说明不代表新一轮部署环境验收。
