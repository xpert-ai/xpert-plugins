---
title: 资源目录页面
description: 查询、浏览和使用已导入或公开的资源
---

<Warning>
目录页面、查询与导航参数处于 Beta 阶段，后续可能发生破坏性调整。
</Warning>

三个页面通过现有 Workbench View 接入，由平台负责标签页、菜单和聊天界面：

| 页面 | 本批提供的内容 |
| --- | --- |
| 探索示例 | 已导入及公开的示例任务列表，查看详情或准备到对话输入框 |
| 模板库 | 分析模板、视觉主题及组件分类，查看固定版本与字段映射 |
| 添加数据 | 原有数据源、Dataset 管理，以及公开数据集目录入口 |

目录展示“我的资源”和“公开资源”。列表使用服务端分页、搜索和主题外观筛选，优先显示请求语言的资源标题与描述；没有翻译时使用资源原文。查询参数通过 SDK 导航命令保存，刷新或再次打开时可以恢复。语言更新保留当前筛选，项目作用域更新则清除旧资源状态。

卡片接入已有的详情、ZIP 导入与任务准备组件。使用示例只填入文件、提示词和技能，发送操作由用户完成。只读用户可以浏览，但不能导入或准备任务。公开资源附件的复制仍受既有后端能力限制。

数据来自已持久化的资源版本，封面由宿主按权限读取；没有封面时显示占位图。本批不预置模板清单、示例数据、提示词或封面文件，也不引入静态目录文件作为资源存储。

精选目录、探索首页专题布局和具体内容包后续单独审核。此文档描述页面行为，不代表新一轮真实部署环境验收。
