---
title: 数据集存储
description: 可复用查询定义、作用域隔离与草稿修订约束
---

数据集保存一份可复用的 Analytics Binding 和筛选默认值。预览时重新执行查询，保存内容不包含查询结果行。数据源发现与查询继续使用平台 Analytics Runtime Capability。

## 存储方式

- Artifact 类型为 `live-dashboard-dataset`，采用仅草稿生命周期。
- 数据集定义包含稳定 ID、名称、描述、Binding 和筛选默认值，JSON 内容最大为 200,000 字节。
- 定义文件通过 Artifact Content 写入，再由 Artifact Drafts 关联文件引用与修订号；读取通过 Workspace Files 完成。插件不绑定具体文件存储后端。
- 列表元数据保存名称、描述、来源、Provider 和字段数，不缓存业务数据。

## 访问范围

个人数据集隔离到当前 Assistant 和用户；项目数据集隔离到当前 Project。每次读取或修改都会校验租户、组织及资源归属，并重新检查项目角色和 Assistant 绑定。

项目数据集定义仅供可编辑项目的用户访问。普通成员不能读取定义草稿；离开项目、失去编辑权限或解除 Assistant 绑定后，后续访问会被拒绝。Artifact 文件入口也执行个人所有者或项目编辑权限校验。

## 保存、预览与回收

保存前执行来源查询验证。来源访问被撤销或查询无效时，不写入新的定义修订。预览执行当前查询，仍受数据源权限约束。

新建使用 `expectedRevision: 0`；修改与回收使用当前修订号。版本冲突由宿主草稿接口拒绝，避免覆盖他人的修改。回收后，数据集不再出现在有效列表中。

本模块提供数据集持久化服务与 Artifact 类型。数据管理视图、模板生成、公开资源发布及 ZIP 迁移由各自模块接入。
