## 已安装环境

| 场景 | 结果 |
| --- | --- |
| 匿名、组织外用户 | 分别拒绝 API 访问；独立页先登录再返回原 URL |
| 组织成员读取 | 能打开正式版本；不能通过 owner 管理接口读取 Artifact |
| 来源授权 | 无数据源权限的成员查询被拒绝，获得权限后成功；没有使用创建者身份代查 |
| PostgreSQL / data-xpert | 通过展示查询接口分别返回 6 行，重复查询使用新的执行 ID |
| ECharts 浏览器 | 全部净销售额 5700，华东筛选 3500、明细 3 行；图形和明细正常显示 |
| 刷新与重开 | 刷新保留筛选并产生新查询，重开恢复正式 v2 与默认总额 5700 |
| 固定与最新 | 固定 v1；相同配置复用链接；切换为最新后读取 v2，原链接失效 |
| 撤销 | 原链接读取失败 |
| 查询边界 | 发布指令、SQL 载荷覆盖、未声明 Binding、其他版本目标均被拒绝；HTML 直接网络请求被 CSP 阻止 |
| 私有脚本依赖 | Workspace Script 正式看板返回私有依赖诊断并阻止开启分享 |

独立页使用完整可用屏幕宽度；WorkBench 新增分享按钮后修复窄屏工具栏溢出，并通过 320–1280 像素的既有响应式回归。已打开页面在撤销后不会主动清除已显示的数据，但下一次查询/重开重新检查权限。

## 独立页浮层操作栏

同日追加 UI 调整：工具栏默认收起为半透明按钮，悬停临时展开，点击或触摸保持展开。收起按钮、Escape 和点击 HTML 画布均可关闭；标题、正式版本、更新时间、刷新及标准模式筛选位于浮层，画布不再为工具栏预留高度。

在实际 xpert-pro 独立页使用创建者正常登录验证：1440×1000 视口下，展开前后画布均从 y=0 开始、保持 1000 高；375×812 视口中浮层保持在屏幕内，触摸点击可展开。鼠标从按钮移入浮层可连续操作，移开自动收起；点击固定、键盘打开/Escape、关闭和点击 iframe 画布收起均通过。刷新请求成功，华东筛选仍为 3500。构建、48 项插件测试、既有 Workbench 浏览器回归和插件生命周期验证通过，检查了收起、展开及窄屏截图。

真实点击发现并修复了独立页继承插件 iframe 沙箱而无法启动登录应用的问题。作者 View 声明 `artifact.presentation.open`，调用平台受控命令打开同源 Artifact 展示 URL；新窗口清除 opener，展示页仍重新检查权限。没有增加 iframe 的同源/弹窗逃逸权限，也没有开放 HTML 网络请求或 Binding 以外的查询。浏览器入口只导入 contracts 类型，避免将需要动态求值的运行时依赖带入受 CSP 限制的包。

新增平台打开命令、功能模块注册与销毁清理及 ChatKit 宿主授权共 20 项定向测试通过；Cloud TypeScript、contracts 构建、Live Dashboard 54 项测试、Workspace Script 18 项测试、生产前端 Workbench 回归和插件生命周期通过。共享页面使用普通登录会话，本次没有重新验收团队成员的 data-xpert SSO 新账号流程，也不属于 npm 发行或正式版本发布验证。本地插件使用当前平台源码构建的 contracts/SDK；其包版本标签较插件声明范围旧，不能据此声称已验证公开包版本兼容性。

浏览器自动化使用正常登录和组织选择，没有复制浏览器会话凭据。测试成员在验收后通过平台接口软删除，临时角色权限及本地凭据文件已清理；空角色记录因已删除用户的外键引用保留。业务看板的草稿和正式版本保持原有内容。
