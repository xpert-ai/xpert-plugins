Superstore 企业 BI 提供一个完整的零售分析案例。数据来自 Tableau 官方教学工作簿，包含 2021–2024 年的 10,194 个订单行、5,111 个订单与 804 个客户，属于虚构演示数据。

## 查看效果

在 Live Dashboard 的样例入口选择 **Superstore 企业分析**。管理员完成下述数据准备后，助理会在当前 ChatKit 项目保存三个草稿；通过聊天回执卡片或顶部项目/看板级联选择器打开：

- **零售经营总览**：经营 KPI、月度趋势、区域销售贡献和品类明细。
- **商品盈利分析**：子品类利润排序、销售与利润关系以及亏损标识。
- **客户与退货分析**：客户分群、客单价、退货订单占比与关联销售额。

年份、区域、品类筛选会更新当前看板全部图表与指标。三个草稿的筛选状态独立，项目归属与 ChatKit 同步。原来的三个入门样例继续保留。

三张企业看板采用[不同视觉风格](/visual-styles)：总览使用 Trend Workspace 浅蓝指标侧栏，盈利页使用 Profit Atlas 深色分析台，客户页使用 Customer Brief 暖色报告；共同保留双层标签筛选器。通用 CSS、选择器、图表组件和组合说明随技能安装，Agent 可据此制作同风格的其他业务看板。已有草稿需要明确要求 Agent 升级样式；更新助理模板不会自动覆盖它们。

## 管理员准备数据

安装 Data Xpert analytics provider，并为工作空间绑定有权限的 PostgreSQL 数据源。使用插件技能目录 `examples/superstore/orders.csv` 及 `import.json` 导入一个新表，再按 `semantic-model.json` 建立、验证并发布 SQL 语义模型。

发布模型需要一个可访问的业务域；为实时看板助理绑定发布后的本体资源及只读查询权限。安装 App 本身不会授予数据权限。完整步骤、动态 Binding 查询计划与预期结果位于该目录的 README。

数据通过 Data Xpert 已发布本体资源实时查询，页面内不包含业务数据快照。当前环境未准备模型时，助理会说明缺少的数据接入，不替换为少量演示行。

## 指标口径

订单数与客户数由后端在当前筛选范围内去重，不能跨月份/品类相加。利润率使用合计利润除以合计销售额。金额单位 USD，保留源数据精度后再格式化展示。

退货原表的 800 行对应 296 个不同订单；导入前去重，避免销售额被关联放大。退货关联销售额并非退款金额，也不是收入损失。页面不展示样例无法支持的预算、库存、净退款或客户流失指标。

## 来源与复现

数据来源为 [Tableau 官方 Data App 示例](https://tableau.github.io/extensions-api/docs/dataapps/trex_dataapp_examples/)，固定版本哈希和 Apache-2.0 许可随样例保留。视觉信息层次参考 [phData 的企业经营看板案例](https://www.phdata.io/blog/building-an-executive-dashboard-in-tableau/)，页面代码为独立实现。

数据重建程序校验原工作簿哈希，产生 CSV、语义模型模板和筛选基准。页面构建程序生成三个自包含 HTML，按 Live Dashboard 技能正常预览与保存。配方升级不会覆盖用户已有看板。
