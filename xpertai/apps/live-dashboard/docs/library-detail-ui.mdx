---
title: 资源详情与使用组件
description: 固定版本检查、导出、公开管理与任务准备
---

<Warning>
此组件与预览 Action 处于 Beta 阶段，数据契约和交互可能发生破坏性调整。
</Warning>

`ResourceDetail` 展示所选资源的固定版本、许可证、依赖及可用操作。未安装和待实现的目录项仅展示说明，不触发执行。

- **导出**：向宿主申请 `library-v2/<releaseId>` 的下载授权，下载资源 ZIP。
- **公开管理**：依据服务端返回的能力显示公开或撤回入口；公开前需要用户确认。文件资源的公开复制仍受已有后端限制。
- **使用示例**：准备文件、提示词和技能后插入对话输入框，由用户发送。
- **使用分析模板**：选择 Dataset 固定修订，按字段类型和可空性匹配角色，再填写模板参数。准备请求生成配方文件并插入输入框，后续由 Agent 执行。

预览图片通过 `resource-thumbnail` 读取资源版本中声明的封面或预览附件，限制为 2 MB 以内的图片。服务端检查资源访问权限及所有权，通过既有文件服务读取、校验内容，并在返回前重新确认权限。调用方不接触存储路径或存储类型。

通用图片组件与具体封面清单分离：没有可用图片时展示占位图。页面可在后续内容接入中显式提供备用图片。

本批包含独立组件、目录展示类型及预览接口；完整目录页入口、模板内容和封面资产留待后续审核。本说明不代表新的部署环境验收。
