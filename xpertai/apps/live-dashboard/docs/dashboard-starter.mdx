---
title: 新建 Dashboard 初始界面
description: 从数据、模板或示例开始创建看板
---

<Warning>
初始界面与导航入口处于 Beta 阶段，后续可能发生破坏性调整。
</Warning>

具有编辑权限且尚未选中看板时，个人工作区和项目工作区都展示初始界面。它仅占用已有 View 的内容区域，使用共享 shadcn 组件及 Tailwind 字体、间距样式。

| 入口 | 行为 |
| --- | --- |
| 我的数据 | 打开已有数据源和 Dataset 管理页面 |
| 模板库 | 打开已导入及公开的分析模板、主题与组件目录 |
| 探索示例 | 打开已导入及公开的示例任务目录 |

三个入口只通过 `workbench.navigation.open` 请求平台打开对应 View，不发送聊天消息，也不创建或发布看板。导航处理中禁用入口；失败时展示错误，允许重试。

“交给助理分析”沿用已有的开始分析操作：先清除上一个看板的编辑目标，再向当前对话发送开始分析请求。它与示例目录中的“使用此任务”行为不同，后者仅准备输入框草稿，等待用户发送。

本批不预置模板、示例数据或封面。相关目录功能见[资源目录页面](./library-directory-ui)。
