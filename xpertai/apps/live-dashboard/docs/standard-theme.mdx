> **Beta 阶段**：主题标识、变量映射及 `visualTheme` 存储字段可能随时发生不兼容变更，暂不保证向后兼容。

标准看板通过宿主提供的主题变量设置背景、文字、边框、强调色和字体。业务数据继续由原有 Binding 查询，主题不改变指标、字段映射或权限。

## 定义与更新

看板定义可以包含可选的 `visualTheme` 字段，更新时也可以单独修改它。

| 值 | 行为 |
| --- | --- |
| `system` 或省略 | 使用宿主的背景、卡片、文字、边框与字体变量 |
| `slate` | 次级背景使用宿主的 muted 变量 |
| `contrast` | 主边框使用宿主的前景色变量 |

未提供主题字段的旧定义仍可读取。缺失的宿主变量保留渲染器自身样式，不写入空值。

## 生效范围

主题样式注入标准看板的隔离 iframe，宿主根元素的主题样式或 class 变化后重新渲染文档。此过程不保存看板，也不重新请求业务数据；iframe 内的临时交互状态会重置。

HTML 模式由作者的文档与锁定的文档库控制展示，不使用这套标准渲染器主题。它与 [HTML 看板视觉风格](/visual-styles) 是不同的展示机制。

本批仅提供主题字段与渲染适配，不包含主题库条目、封面、示例数据或主题选择界面。后续模板功能可复用这套能力。
