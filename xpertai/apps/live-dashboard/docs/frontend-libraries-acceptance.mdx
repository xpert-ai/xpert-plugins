## 实现范围

平台 `@xpert-ai/plugin-sdk/artifact-document` 增加通用依赖锁与源码校验，
锁包含 ID、精确版本、脚本格式、全局名称与 SHA-256。
宿主在 CSP 和页面 SDK 之后、作者脚本之前注入校验后的代码，保持原有 iframe 隔离与查询协议。
这些能力同步至 Xpert Pro；平台没有引入 ECharts、Three.js 或看板专属的数据源逻辑。

Live Dashboard 插件负责图库允许列表、构建与许可证，目前打包 ECharts 5.6.0 和 Three.js 0.185.1 核心库。
使用图库的版本以 `xpert.live-dashboard.package/v1` 保存完整 HTML、Binding、控件、依赖锁和实际库源码。
源码与定义共享 Artifact Version 的内容校验；省略 `libraries` 的修改保留原始依赖字节。
历史版本无需当前插件继续提供相同版本的库，无图库的旧定义保持兼容。

Agent 新增 `dashboard_libraries` 工具，只读取元数据与使用说明，不向模型传递库源码。
`dashboard_create_html` 和 `dashboard_update` 接受允许的图库 ID 列表；
发现数据、真实预览、筛选证据、版本 CAS 与后台浏览器预检继续适用。
预检与实际页面使用完全相同的依赖快照。
用法和限制见[固定前端图库](frontend-libraries.mdx)。

## 真实 SSO 验收

在本地 Xpert Pro 与 data-xpert SSO Workbench 使用真实 ChatKit 和已配置模型，
通过一句话要求创建 ECharts HTML 看板。业务来源为 PostgreSQL 验收订单，
指标是 2026 年第三季度已支付订单的实付减退款，单位人民币元，按月和区域汇总。
本轮验证 ECharts 的展示与版本能力；数据源适配器本身未修改，
此前本体与 Workspace 脚本的 HTML 验收记录见[持续修改验收](evolution-acceptance.mdx)。

| 检查 | 实际结果 |
| --- | --- |
| 一句话生成 | Agent 发现、预览、验证筛选，调用图库发现工具，以 `libraries:["echarts"]` 保存 v1 |
| 后台预检 | 真实 Sandbox Browser Job 成功，执行同一份 ECharts 源码和默认 Dataset |
| 持续修改 | 选中当前作品后提出自然语言修改；`dashboard_open({})` 取得正确目标，`dashboard_update` 保存 v2 |
| 页面变化 | 浅色销售驾驶舱的折线图改为深蓝金色经营指挥屏的分组柱状图 |
| 身份与依赖 | Artifact ID、Binding、ECharts 版本及源码摘要保持不变，修改工具未传入 `libraries` |
| 保存重开 | 刷新浏览器后打开当前版本，再通过版本菜单打开 v1/v2，均正确渲染 |

生成过程中曾选错文件写入工具的参数字段，工具拒绝该请求；
Agent 在同一轮自行更正后继续保存，未手工改写生成 HTML 或伪造成功回执。
初始汇总表被标成“订单明细”；修改请求明确纠正为“月度区域汇总明细”。
这也说明浏览器预检不能替代业务标签与展示语义验收。

## 数据与刷新 oracle

独立预期沿用验收订单定义，不从被测查询返回值反推：

| 月份 | 华东 | 华西 |
| --- | ---: | ---: |
| 2026-07 | 1,000 | 800 |
| 2026-08 | 1,500 | 900 |
| 2026-09 | 1,000 | 500 |
| 合计 | 3,500 | 2,200 |

两个版本均验证默认合计 5,700、华东 3,500、华西 2,200。
除了页面数字和表格，还读取真实 ECharts 实例的 series，验证线图／柱图的数据与独立预期一致。
临时把华西七月的一笔实付增加 100 后，刷新使图表数值 800 → 900、合计 2,200 → 2,300；
恢复来源后再次刷新回到原值。筛选值和 HTML 文档实例均保留，全部临时金额已恢复。

两版接口共验证 12 次成功查询／刷新与 12 次拒绝请求；
初始版本的定义摘要、两版的依赖源码与锁定摘要均逐一核验。
历史版本保存的是页面与查询定义，打开时仍查询当前授权的最新业务数据。

## 查询与资源边界

- ECharts 已加载时，浏览器尝试直接 fetch 后端、读取父页面 DOM、查询未声明 Binding，均被拒绝。
- 服务端继续拒绝额外 SQL payload、替换 Provider、替代 Binding、替换数据源、未知控件；未声明 Binding 返回 403。
- 回归验证未知图库、伪造版本、缺失快照、源码摘要不符、重复全局名称、保留的 SDK 全局名称和超限源码。
- 在受控测试中移除当前图库目录解析器后，已保存版本仍从自身快照取得原始依赖。
- 没有开放 CDN、动态模块导入、任意网络、宿主存储、跨 View Action 或额外数据访问权限。

- 本地部署验证成功；私有执行回执、Job ID、版本记录与截图保留在验收环境。

Three.js 目前完成核心库与场景对象验证，未完成真实 SSO 中的 WebGL GPU 页面验收；
不包含 addons、外部模型、纹理、WebGPU 或 worker。

该结果是本地集成验收，不代表生产发布、任意页面语义正确性或多租户压力验证。
