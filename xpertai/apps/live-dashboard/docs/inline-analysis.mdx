---
title: 对话内分析结果
description: 用受控查询预览生成单个可视化场景，无需保存整个看板。
---

启用 LiveDashboard 中间件的 Assistant 可以调用 `dashboard_present_analysis`，
直接在当前单聊或群聊中展示一次分析结果，然后继续分析或给出最终结论。
这条路径不需要新建看板、编写 HTML 或保存文件。

## 调用流程

1. 发现当前用户可用的数据源，确认字段、指标口径和查询契约。
2. 使用 `dashboard_preview` 或 `dashboard_preview_binding` 得到本次运行的 `previewId`。
3. 调用 `dashboard_present_analysis`，指定 `previewId`、标题、展示方式和精确字段 ID。
4. 收到 `display.status: emitted` 后才说明结果已展示。可以继续查询和分析。

| 参数 | 约束 |
| --- | --- |
| `view` | `bar` 柱图、`line` 折线图、`table` 表格、`metrics` 指标 |
| `fields` | 1–6 个精确字段 ID；图表恰好两个，依次为分类/时间/标识字段和度量 |
| `orderBy` | 显式指定度量字段和 `asc` / `desc`，先排序再截取；排名仅覆盖已返回的数据 |
| `language` | 中文对话使用 `zh-Hans`，英文使用 `en`；省略时使用运行上下文语言 |
| `maxRows` | 1–20，默认 10；超出的数据明确标为部分结果 |
| `previewId` | 仅限本次运行成功查询产生的凭证，不接受历史会话里的凭证 |

工具不会自动汇总重复分类或猜测排序意图。Top N 必须显式传 `orderBy`，仅设置 `maxRows` 得到的是前 N 行，并非最高 N 项。指标视图要求查询结果只有一行。
超出安全数值精度的 decimal/int64 应用表格展示，保留原始字符串；空值不转换成零。
指标视图用名称、大数字与数据集声明的单位分别展示，多指标在窄屏自动换行。
decimal/int64 的千分位格式化保留原始精度，不补造缺失单位。
卡片页脚默认显示结果完整性和按查看者本地时区格式化的查询时间；数据集、展示行数与原始数据获取时间放在“查看详情”中。
这些公开信息由通用 Widget `presentation` 字段承载，展开详情不会发起查询或恢复原运行会话。
历史卡片可以使用新版容器；只有新版工具生成的结果带有新的指标布局与页脚，不改写已有消息内容。

## 权限与展示边界

工具只接收展示参数。实际 Binding 由运行内凭证解析，使用当前成员的身份重新校验权限、
重新执行同一个查询，再展示此次执行的结果。模型不能提交任意数据行、SQL、HTML、URL 或用户身份。
这不是一项新的数据授权：群聊中仍需发起成员具有数据权限。

当前实现返回既有的 flat A2UI Widget：指标与表格使用文本组件，图表使用插件生成的
静态 SVG 图片组件，不携带脚本、外部资源或交互会话。它是结果快照，不是新的 MCP App，
也不具有 MCP App 的交互能力。群聊自动投影这类通用组件；平台与 ChatKit 不识别此工具名称，
也不需要 Live Dashboard 专用分支。

展示卡片不代表请求完成。群聊中间结论用 `reply` + `replyStage: progress`，
最后结论用 `replyStage: final`。既有的最终答复去重逻辑保持生效。

跨项目共享看板的资源分析授权仍通过 resource analysis 路径执行；
本工具不把共享看板权限转换成源项目查询权限，也不接受共享资源查询结果的任意复制。
将这类结果连接到可视化需要受信任的查询凭证，不能绕过授权边界。

## 验收建议

让已启用 LiveDashboard 且有查询权限的 Assistant：

> 查询库存金额最高的 5 个工厂，先在对话里展示柱状图，再继续给出分析结论；不用创建看板。

检查图表与精确值表、时间和完整性标记，刷新后确认群聊卡片仍可见。
撤销查询权限后再次调用应失败且不发布卡片。

自动测试覆盖凭证隔离、再次授权、稳定消息 ID、数值精度、空值、部分结果与 SVG 转义。
自动测试通过不等于模型调用、真实数据授权或客户端显示已经完成验收；这些需要运行实例验证。
