## 发现与修复

首次制作暴露执行步数不足，已为制作模板配置有限的 300 步和 48 次模型调用预算。配方明确成功保存即结束，避免无意义的再次打开和保存；权限、预览和保存回执保护保持有效。

首次短提示的生产质量试跑误用了项目中既有销售数据，该结果判定失败并移入回收站。入口已明确指定完整配方、随附数据和业务指标，禁止替换为其他看板。更新后重新从按钮发起，使用正确生产质量数据并通过上述验收。模型中间曾提交不合法文件路径，路径保护拒绝后由助理纠正；最终成功不代表取消工具输入校验。
