## 目录和可执行内容

探索首页提供分析与洞察、数据与知识、定时任务和技能扩展四个入口。分析与洞察进入示例列表，数据与知识进入已有数据管理；定时任务和技能扩展目前只说明预留范围。

模板目录包含 6 个分析模板、43 个视觉主题和 37 个组件，支持分类、搜索、主题外观筛选和服务端分页。这 86 项是展示占位，只有说明和原创 SVG 形态预览，不代表可执行模板。预览中的图表和值为示意，不是查询结果。

十个分析任务另以 V2 内容包提供：酒店经营分析、出境旅行、Steam 市场、天气预警、品类贡献、电商经营、全球资产、法律分析、订单促销和酒店取消归因。其中酒店经营分析使用固定 HTML 模板，其余任务提供分析提示词，由 Agent 在用户发送后执行。联网检索、Kaggle MCP 和外部技能需在目标环境另行提供，导入不会安装或授予这些能力。

目录蓝图保存在 `src/lib/library/catalog-blueprints.json`，仅用于展示和按逻辑身份匹配当前用户已导入的资源。用户上传的正文、固定版本和公开状态仍由数据库管理，不写回静态目录。未导入任务禁用使用入口；浏览页面不会自动灌入数据。

## 生成和导入 ZIP

从源码仓库的插件目录完成构建后，执行以下任一命令，输出文件必须尚不存在：

```sh
node scripts/export-explore-v2.mjs ./explore-insights.xpert-library.zip
node scripts/export-hotel-v2.mjs ./hotel-operations.xpert-library.zip
```

完整探索包包含 10 个任务、15 个资源和 14 个附件。酒店独立包包含任务、模板、主题、数据集四个资源及两个附件。探索包为酒店任务新增封面并使用版本 `2.1.0`，保留酒店独立包 `2.0.0` 的依赖摘要。

作者脚本在源码仓库运行，不属于插件启动流程。将 ZIP 通过[导入预检与确认](/library-import-ui)导入为私有资源，再从目录使用。目标客户部署可以导入同一个 ZIP，重新分配本地记录；数据源凭据和系统存储配置不在包内。已导入资源可从详情导出完整依赖闭包，见[资源库与 ZIP 迁移](/library-storage)。

## 数据口径和封面

酒店数据为 720 条、订单数据为 1080 条、天气数据为 360 条确定性合成记录，均明确标注演示用途。酒店房费为未取消预订的 ADR × 晚数估算，不是实际收入；取消率使用状态已知的预订为分母。模板按显式字段映射查询，不把业务数据行写入 HTML。

十张 WebP 任务封面为重新生成的插图，四张分类 SVG 和 86 张目录 SVG 为原创代码绘制。素材来源、生成记录与摘要分别保存在 `assets/explore/PROVENANCE.md`、`assets/explore/generation-prompts.json` 和 `assets/library/catalog/provenance.json`；界面不依赖远程图片服务。封面和图形只说明任务主题，不作为分析证据。

点击使用只向 ChatKit 准备可编辑的提示词、附件和技能，发送由用户完成。准备配方与保存回执的约束见[Agent 交接](/template-agent-handoff)。

## 验证边界

内容测试检查包的确定性、依赖闭包、数据数量、固定版本保留、图像摘要和酒店查询交互；目录测试覆盖分页、筛选、只读及未导入状态。单元测试和生产包挂载检查不等同于真实 ChatKit、Agent、外部数据能力或客户部署验收。其余九个任务不应宣称已完成最终分析产物验收。
