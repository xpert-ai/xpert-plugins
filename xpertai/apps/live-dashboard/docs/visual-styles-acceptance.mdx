## 构建与生产 SDK

- Nx 构建、插件 metadata、插件加载 harness 和 `verify:dist` 通过；194 项自动化测试、5 项数据基准检查通过。
- 生产 Artifact Document SDK 的三页浏览器回归通过：完整 HTML 预检、区域/年份/品类筛选、所有 Binding 更新、刷新、空结果、截断、失败与恢复、键盘、390px 窄屏、深色模式与菜单边界。页面错误记录为空。
- 对照用户原型和 1440px 实现，检查字体、布局、颜色、图形与业务内容。修复散点标签靠近横轴和客户页初稿字号偏小的问题，重验通过。
- 实际打包后的 45 个主题、配方、截图和文档文件与源码匹配；包内 Sandbox Action 与文档库通过内容校验。
- 总览 HTML、已有 ECharts/Three.js/Trend Workspace 库的原始内容未改变。新增主题可选，每个文档最多选择一种主题；混合主题请求被校验拒绝。

这一层使用独立数据基准提供查询响应，证明渲染与生命周期；真实安装验收见下文。

## 安装与实际 Agent

- 拉取当前分支、安装冻结依赖、重启对应本地服务后验收；插件通过平台部署流程刷新，API 重启后健康检查和实际 View 通过。
- 在原实时看板助手画布执行“从模版更新”，复核后发布同一助手版本。助手身份、模型、工作空间与 API/App 访问设置不变。安装后的主题指南、组件与完整配方逐字匹配源码。
- 平台真实 Agent 阅读技能与完整配方，分别打开两张原看板、编辑当前 HTML 副本并执行 `dashboard_update`。本轮 16 次工具调用无错误，两个保存回执均成功；没有由开发者直接写入业务 Artifact。
- 商品盈利分析更新到草稿 r3，使用 ECharts + Profit Atlas；客户与退货分析更新到草稿 r3，使用 ECharts + Customer Brief。二者最终 HTML 与对应配方一致。
- 经营总览保持草稿 r2，保存定义整体与原记录一致；没有创建重复看板或发布正式版。

- 三张看板、六组全量/区域/年份/品类及组合筛选，共 54 次真实 Binding 查询逐行匹配独立数据基准，未发生截断。
