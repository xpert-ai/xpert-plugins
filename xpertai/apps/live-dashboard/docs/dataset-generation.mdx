description: 校验数据集修订与字段映射，创建独立的标准看板草稿

> **Beta 阶段**：生成接口、预设标识及字段映射约定可能随时发生不兼容变更，暂不保证向后兼容。

`template-create` 是添加数据 View 暴露的基础动作。调用方提供已有数据集的 Artifact ID、预期修订号、新看板定义 ID、标题、展示预设、主题和字段映射，服务在当前宿主授权作用域中创建看板草稿。

本批不包含模板库选择界面、模板目录条目、封面、酒店示例或公开数据。这里的预设是标准图表的组装规则，业务查询来自用户已保存的数据集。

## 生成规则

| 参数 | 行为 |
| --- | --- |
| `datasetId`、`datasetRevision` | 读取数据集当前定义；修订不一致时拒绝生成，调用方需要重新读取并确认映射 |
| `id`、`title` | 用新 UUID 创建独立看板；已有草稿不被覆盖 |
| `template` | `comparison` / `bar` 使用柱状图，`trend` / `line` 使用折线图，另支持 `area`、`pie` 和仅明细的 `details` |
| `x`、`y` | 图表模式要求字段存在且 y 是数值字段；x 必须覆盖数据集输出粒度，不能把明细伪装成汇总 |
| `theme` | 复用[标准看板主题适配](/standard-theme)的 `system`、`slate`、`contrast` |

每个草稿包含一个 Binding、对应筛选控件和一张明细表；图表模式额外包含主图。明细表最多展示输出定义中前 30 个字段，完整 Binding 字段定义仍保留。多个粒度维度的查询需要先在数据集中聚合为适合该图表的粒度；此接口不会擅自改写查询或执行二次聚合。

数据集的筛选默认值同时复制到 Binding 参数与看板控件，保持默认查询一致。输入严格校验，不接受额外的用户身份、源连接、原生查询或 HTML 参数。

## 权限与保存

服务先验证数据集所属租户、组织、用户或项目作用域及当前编辑权限，再走现有看板保存流程，重新查询当前授权数据并校验筛选条件。数据源权限撤销、字段不匹配、查询失败或修订冲突时，不产生成功的草稿回执。

成功返回新看板的 `artifactId`、`draftRevision` 和 `status: draft`，不自动发布。看板保存查询定义和展示结构，不保存预览结果行。已存在的看板修订通过原有 CAS 约束保护。

生成后的看板持有 Binding 副本。后续修改或回收数据集不会同步改动这份看板；看板查询仍受实时数据源权限约束。
