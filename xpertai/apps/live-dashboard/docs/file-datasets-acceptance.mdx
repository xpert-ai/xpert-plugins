## 范围与运行方式

2026-10-18，在本地 xpert-pro 中使用现有真实模型，从 Chat 输入业务请求，经平台 SandboxFile 编写 HTML、看板工具预检并保存工作草稿。文件插件继续通过 WorkspaceFiles 和 Dataset/Binding 查询 CSV、JSON、XLSX；平台没有新增文件格式判断或看板专用查询分支。

本次更新看板插件后重启 API，并核对 Assistant 工作区已安装技能与源码一致。没有提供预制页面、脚本或预期金额给 Agent，也没有手工修补生成 HTML。本次不是新一轮 data-xpert SSO、人工发布或正式发布验证。账号、资源身份、原始回执和截图仅保存在本地。

## 一句话生成与页面闭环

独立业务基准为 7 条输入、6 个月份/区域分组：总额 5,700 元、华东 3,500 元、华西 2,200 元。页面采用已打包的 ECharts 5.6.0。

| 场景 | 实际结果 |
| --- | --- |
| CSV 单来源 | 一句话生成并保存蓝色 HTML/ECharts 看板；总额、月度区域趋势和明细一致。 |
| JSON 单来源 | 一句话生成并保存深色金色页面，保留真实区域筛选及刷新。 |
| XLSX 单来源 | 一句话生成并保存浅色绿色页面，聚合趋势与原始明细分别查询，合计一致。 |
| 三来源新会话 | 补强说明后，新开会话一次业务请求生成三个独立面板，共同区域筛选查询全部三个 Binding，不重复合并三个来源的金额。 |
| 筛选与系列 | 全部、华东、华西均逐一核对 KPI、明细和 ECharts 实际系列；被排除区域不残留零值系列。 |
| 源文件更新 | 分别增加 CSV/JSON/XLSX 首条金额 100/200/300 元；保留华东筛选刷新后分别显示 3,600/3,700/3,800 元。工具栏和页面内刷新均实际发起查询。 |
| 重开恢复 | 资源卡片在 ChatKit Workbench 打开；关闭重开和刷新浏览器后恢复保存的草稿、标题和默认筛选。刷新不替换已挂载 HTML 文档。 |

源文件在测试结束后恢复。以上数值来自独立测试数据，不是根据页面结果反推期望值。

## 跨轮编辑

对同一个三来源看板连续发出两次修改请求：第一轮改成深蓝金色并修正筛选后的系列，第二轮修改标题并添加金额及不重复合计说明。Agent 通过 `dashboard_open` 读取独立编辑副本，使用平台文件工具编辑，再调用 `dashboard_update`。

检查时点的草稿修订为 r1 → r3 → r5：两轮均分别保存页面与标题，因此每轮产生两次修订。Artifact ID、草稿 ID、Bindings、controls 和依赖快照全部保持一致；实际保存 HTML 的散列与最近一次 HTML 保存回执一致。正式版本数保持为零。

第一轮修改后的筛选、两种刷新、资源卡片重开和浏览器恢复均通过。最终 r5 修改稿的源文件更新、筛选、两种刷新、资源卡片重开与浏览器恢复也全部通过，确认后续编辑没有破坏查询逻辑。

## 查询与权限边界

- 保持同一访问者 JWT，撤销 Assistant 文件访问或 DATA_SOURCE_VIEW 后，CSV/JSON/XLSX 的发现与查询均拒绝；恢复权限后下一次请求成功。测试者不继承工作区成员权限，临时授权已清理。
- 已保存查询拒绝未知 Binding、未知控件、文件路径与身份、读取配置、URL、Provider、Binding 内容及 payload 覆盖。测试覆盖新建与持续修改后的看板。
- HTML 不能直接请求后端或读取父 DOM；页面始终通过已保存 Binding 及声明的控件取数。
- 本次没有放宽版本并发、文件授权或数据查询规则。

## 发现与处理

1. 初轮 XLSX 页面的刷新按钮调用 `live.refresh()` 时遗漏 Binding ID；工具栏刷新正常，但页面内刷新没有查询。预检新增有界原生按钮交互，工具返回与技能明确每个刷新必须传入 Binding ID。重新生成后两种刷新均通过。
2. 初轮三来源页面只过滤浏览器已有数据。原生数据下拉现在用 `data-dashboard-control` 显式声明关联控件；纯展示下拉用 `data-dashboard-presentation`。预检检查实际查询及共享控件传播，不根据控件名称猜测用途。
3. 后续首稿虽正确查询，但仍把排除区域绘制成零值系列。真实 UI 验收发现后，经同一 Artifact 的后续编辑修复；图库工具说明和技能强调从本次 Dataset 派生系列。新会话生成的三来源看板再次独立通过完整闭环。
4. 生成过程中的渲染回调错误被保存预检拦截，Agent 在同一轮中自行修复。跨轮编辑时，平台文件工具拒绝覆盖已有文件，Agent 改用编辑工具后成功保存。失败调用不计为保存成功。

预检使用真实默认预览数据，验证初始 Binding 查询、控件类型与联动及运行错误；它不认证业务语义，也不穷举全部自定义交互。已有保存页面仍可打开；编辑后重新保存时需补齐原生控件标记。上述结果证明本次真实用例，不保证任意模型、输入或页面都能一次正确生成。
