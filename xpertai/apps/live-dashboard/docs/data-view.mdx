> **Beta 阶段**：添加数据视图与可复用数据集功能仍在演进。后续迭代可能随时引入不兼容变更，包括视图标识、动作接口、参数及存储格式；Beta 期间不保证向后兼容，升级时可能需要迁移或重新创建数据集定义。

在 Workbench 的新增视图菜单打开「添加数据」。视图按需打开，沿用当前 Assistant 或 Project 的作用域。

## 数据源

「数据源」页签展示当前用户可访问的 Analytics 来源。选择来源后，可以浏览 Provider 返回的目录与数据项、查看字段元数据和查询契约，并选择查询方式。

连接凭据与授权由平台管理。此视图使用宿主提供的数据源，不创建数据库连接或保存密码。来源被撤销后，查询与保存仍由平台执行权限检查。

## 数据集

「数据集」页签支持新建、编辑、查询预览和回收定义。列表按页加载；名称搜索筛选已加载的条目，可以继续加载更多。

新建时选择来源与查询方式，填写查询 JSON，配置输出字段、类型、角色和数据粒度。也可以从已有看板复用 Binding，再调整名称、查询与默认筛选值。

预览展示返回行数、完整性、来源获取时间和执行标识；表格最多展示前 100 行。保存前，后端再次校验查询。修改或回收携带当前修订号，遇到冲突时需要重新打开最新定义。

回收前会显示确认框。失败时保留对话框与错误信息；成功后刷新列表。已复制到看板中的查询不随数据集定义一起删除。

## 作用域与界面

切换项目或对话作用域时清空当前选中项和编辑状态，重新读取宿主数据。仅切换语言或主题时保留当前操作状态。表单、弹窗和表格复用共享 shadcn 组件，适应宿主主题和视图宽度。

查询定义的存储与访问规则见 [数据集存储](./dataset-storage)。
