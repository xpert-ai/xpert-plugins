Trend Workspace 随 `live-dashboard` 技能安装。它提供浅蓝指标侧栏、独立刻度趋势、排名和明细布局，以及带键盘操作的双层标签选择器。Superstore 经营总览采用这一主题；盈利与客户页采用另外两个[可选视觉风格](/visual-styles)。

## 交给 Agent 制作

在实时看板助理中选择项目，描述业务目标并要求：

> 请读取 live-dashboard 技能的 themes/trend-workspace/README.md，使用该主题制作我的经营分析看板。先发现当前授权数据及指标口径，再组合主题布局、筛选器和图表；使用 echarts 和 trend-workspace 受控文档库，查询真实 Binding，校验全量和筛选结果后保存草稿。

技能包包括 `theme.css`、`icons.js`、`select.js`、`charts.js` 和 `layout.html`。它们是可供 Agent 阅读、组合的源文件；主题同时作为 `trend-workspace` 文档库注入并随 Artifact 固定版本、哈希和内容，不依赖开发者手写每张看板或运行本地 Python 构建器。完整 Superstore HTML 是已组合的参考；用于其他业务时必须重新匹配字段、粒度、单位、筛选允许值和 Binding。

## 已有看板的视觉升级

先明确目标看板，让 Agent 读取当前定义、草稿修订与 Binding，再按主题调整布局。保留 Artifact ID、组件 ID、数据源、筛选参数及权限，使用当前修订保存更新。模板更新只更新助理技能和说明，不自动覆盖已有看板。

## 交互与数据边界

- 筛选器支持鼠标、方向键、Home/End、输入定位、Enter、Esc 和 Tab；移动高亮不发起查询，确认选项才应用。
- 选择器保留原有 `data-dashboard-control` 和类型化值；一个筛选共同更新指标、图表与明细。
- 主题提供浅色、深色、窄屏、加载、空结果与失败状态；失败或不完整数据清空旧结果。
- 销售额与利润分开绘图，使用相同时间轴和各自金额刻度。负利润使用红色和明确数值，不依赖颜色单独表达。
- 金额、时间、业务口径来自查询和元数据。主题不提供虚构增幅、目标或结论。

## 维护方式

修改通用主题后，开发者重建受控文档库并验证三个 Superstore 配方。Agent 不必反复输出通用 CSS/JS；长业务页面必须分段写入或使用有界精确编辑，避免模型输出截断。Agent 面向用户制作时直接读取已安装资源；技能、助理模板和配方作为一个版本发布。
