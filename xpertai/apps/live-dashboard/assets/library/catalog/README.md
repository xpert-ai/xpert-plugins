# Live Dashboard catalog previews

These 86 SVG thumbnails are authored with `scripts/generate-catalog-art.mjs`. They illustrate template, theme and component layouts with synthetic chart shapes; they are not executable dashboard content or customer query results.

- 6 analysis templates, 43 visual themes and 37 components.
- `provenance.json` records the generation date, original-code-authored provenance and checksums. Screenshots, host chrome and chat content are not packaged.
- The frontend imports local assets; rendering does not require an external image service or account.
- Titles, categories and descriptions identify the intended use. Catalog metadata has stable IDs and explicit kinds in `scripts/content/library-catalog.json`; unimplemented entries remain placeholders.
- Illustrations do not change the host theme or imply an implemented theme, component, or compatibility with all 43 themes.

These previews are separate from executable resource definitions and use the repository license.
