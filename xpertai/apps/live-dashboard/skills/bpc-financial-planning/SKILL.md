# BPC 年度财务规划预算

适用于用户要看“哪一版编制的、哪一年的销售／费用／投资预算”。同一个 Cube 也可能提供单月生产成本预算与实际分析，那项任务使用 `bpc-cost-expense`。只说“预算”且已有上下文不能确定用途时，先确认要做哪种分析。

1. **核对本次模型和范围。** 从授权来源取得已发布模型的实例、版本、Cube、度量、维度、成员唯一名和当前输出字段。按[取数口径与查询配方](references/query-plans.md)确认 ACCOUNT 与 TIME 层级、金额单位及汇总规则。每家公司使用自己的绑定。复用逻辑字段与已确认的业务含义，保留 native 唯一名的全部空格。
2. **选定预算切片。** 单选预算版本 CATEGORY、编制年度 PLANYEAR、规划年度 TIME 年合计成员和报告币种 RPTCURRENCY。同一编制年度可以规划未来年度。从实际成员列表分别选择两种年度。ENTITY 可选具体组织或经核实的全部组织，明确披露范围。核对 OBJECT、AUDITTRAIL 等其他维度取默认汇总是否会重计，有疑问时先拆分一小段数据或标待确认。
3. **分别取年度和月份。** 年度 KPI 取一个年度汇总。趋势查询沿用同一切片，按该年真实月份和三个科目组展开。预览年度、月度以及新增的组织等绑定，检查实际下发的筛选，逐组对账。把区分累计、年度录入成员和普通月份的证据留在回执里。可按[对账脚本的输入约定](references/query-plans.md#逐组对账)使用[离线脚本](scripts/reconcile.py)。
4. **按确认状态展示。** 默认称 AC01 为“销售预算科目金额”，保留 SignData 的原始符号。业务确认该组全是收入金额、采用贷方负数规则后，才可用 `-SignData` 展示“规划收入”。保留冲销方向。AC08 为费用预算，AC05 为投资预算。费用＋投资按两个原始十进制数相加后再换算、舍入。只有收入定义和金额方向已确认、数据有效且分母为正时，才显示费用／收入和投资／收入占比。缺失值留空，零值保留。
5. **解释月度分布。** 月份缺行与金额为零分别显示。若金额集中在 12 月或其他单一月份，先标“按模型存储期间分布”，确认是否有年度规划集中录入后再解释月度走势。即使月份之和与年度合计相等，也需要这项业务确认。按用户要求隐藏异常数据时注明被隐藏的指标及原因，保留核对入口。
6. **交付。** 分析任务返回有效范围、原始金额、对账结果和待确认项。制作或修改看板时沿用 `live-dashboard` 的选定 Artifact、真实 Binding 预览、筛选测试和草稿保存回执。当版本、年度、币种或组织改变，所有依赖 KPI、占比和图表按同一新条件查询。失败、过期、字段缺失或截断要使相关派生指标失效。
