# BPC 成本与费用模型

这是模型专用子技能。配合 `bpc` 通用入口使用，也能按下面的完整步骤独立执行。公共内容只包含模型合同、查询规则和合成示例；不固定任何公司的数据源、模型实例或金额。

## 1. 验证模型并取得本次绑定

读取 [语义合同](references/semantic-contract.md) 与 [运行时映射](references/runtime-binding.md)。模型逻辑字段固定为 CATEGORY、PLANYEAR、TIME、ENTITY、ACCOUNT、RPTCURRENCY 和 SignData；核实业务含义、层级和实际版本映射符合合同。

从用户当前授权模型解析 native 维度、层级、成员唯一名、Cube 与资源标识。保留原始唯一名和空格，不根据中文标题猜编码，不假定不同环境的底层技术名相同。将核实的映射写成本次本地 runtime binding，保持在公共技能目录之外。

此技能的合同标识是 `bpc-cost-expense-v1`，它只标记本技能内的映射格式和语义版本，不是平台已有的模型 ID 或新增的服务端字段。未经验证，不能仅设置这个标识就宣称模型兼容。

## 2. 确定业务选择

预算/预测版本、预算计划年度、报表单月和报告币种必选；优先使用用户指定或现有看板已确认的条件。组织和科目可选，但“全部科目”仅表示合同中的生产成本六大类。金额单位是显示换算，不是币种转换。

成员候选来自当前模型。模型定义固定不代表金额、可用月份、版本和完整性固定；最新有值月份也不能直接标为已关账。

## 3. 构造两侧查询

| 条件 | 预算侧 | 实际侧 |
| --- | --- | --- |
| CATEGORY | 所选单个预算/预测版本 | A00 对应的精确成员 |
| PLANYEAR | 所选预算计划年度 | DUMMY_PLANYEAR 对应的精确成员 |
| TIME | 所选单月 | 同一单月 |
| ENTITY / ACCOUNT | 所选组织及成本范围 | 同一范围 |
| RPTCURRENCY | 所选单一报告币种 | 同一报告币种 |

使用 [build_queries.py](scripts/build_queries.py) 及本次真实绑定生成原生查询参数。以下命令从技能目录运行；实际工具调用应使用宿主提供的绝对路径：

```sh
python3 scripts/build_queries.py \
  --binding /path/to/current-model-binding.json \
  --budget-version BUD01 --plan-year 2030 --month 2030-01 --currency CNY
```

日期和版本只是调用格式示例。脚本只输出 JSON，不访问网络，不验证当前业务数据，不执行查询或保存看板。输入必须是绑定中明确列出的键；未知成员不能自动拼接。可选 `--entity` 与 `--account-code` 也从映射中精确解析。

执行 Python 需要当前授权环境提供对应运行能力，且脚本与绑定文件对该环境可读；不能把宿主技能路径直接当成沙箱路径。只有文件读取工具时，读取脚本和合同构造相同参数，再通过真实 Provider 预览验证；如实说明未执行生成脚本，不编造命令执行结果。

## 4. 校验结果并计算

两侧必须属于同一筛选快照、查询成功、未截断、粒度唯一、预期科目齐全且金额非空。按科目成员唯一名连接，缺失不补零，双方同时缺一类也不能判完整。

- 预算余额/超支额 = 预算 − 实际；正为余额，负为超支。
- 执行率 = 实际 ÷ 预算；零预算或任一侧不可用时不计算。
- 材料等成本占比使用同版本、期间、组织、币种和科目范围内的分子、分母。

使用精确十进制金额复核，最后换算单位和舍入。负值保留原符号并核对调整/冲回含义。只有查询结果覆盖得到证明时才报告查询范围的比较；业务完整性和关账状态仍需独立确认。

## 5. 交付分析或草稿

分析请求只报告结果和依据。看板修改请求遵循当前 Live Dashboard 技能，读取现有编辑副本，确保参数 name/controlId 与真实 payload.parameterPaths 一致；可选 null 的移除语义由当前 Provider 确认，生成器默认直接省略未选择的可选 slicer。

实现同批次更新、失败使比较失效、忽略过期响应；字段错误不能转成空数据，截断不能标完整。验证版本、年度、月份、组织、科目、币种切换及单侧失败/恢复，缺少验证时如实说明。

最终保存草稿并回读实际 revision 和入口，不用文件已修改或执行 success 代替保存回执。发布、安装或修改连接需要相应授权。本技能不会自行安装其他技能、修改模型或发布看板。
