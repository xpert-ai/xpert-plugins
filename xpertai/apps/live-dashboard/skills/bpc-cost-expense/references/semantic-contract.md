# 成本/费用模型合同 v1

本合同描述可在多个组织复用的逻辑模型。组织间变化的连接、模型实例、技术映射和数据不属于公共合同。它不是所有 SAP BPC 模型的通用字段推断器。

## 固定语义

| 逻辑字段 | 固定角色 |
| --- | --- |
| CATEGORY | 预算/预测/实际版本；实际业务编码 A00；预算版本从当前模型的明确角色映射中选择 |
| PLANYEAR | 预算规划年度；实际使用 DUMMY_PLANYEAR 映射 |
| TIME | 报表期间；本模板为单月；不由 PLANYEAR 自动推导 |
| ENTITY | 组织/工厂，使用模型的既定组织聚合规则 |
| ACCOUNT | 成本科目；当前范围为 PARENTH2、LEVEL01 的六个生产成本分类 |
| RPTCURRENCY | 单一报告币种；两个比较分支相同 |
| SignData | 带符号金额，decimal；保留模型返回的原始十进制值 |

模型的底层 Cube、native 字段/层级 ID、成员唯一名以及返回列的技术名称由环境绑定提供。即使逻辑字段相同，也不能假定底层生成编码相同。不得把某环境的模型 UUID、Cube 或返回列字符串作为所有实例的常量。

成本通常为正；负成本保留并核对冲回/调整，不强行取绝对值。收入的符号规则和有利/不利差异不属于本模板的成本指标解释。

## 计划年度与报表期间

预算计划年度可以包含多个报表年度的规划值。只筛 PLANYEAR 不能替代筛 TIME；必须独立指定两者。不能把所有预算版本相加，也不能把不同时间覆盖的预算和实际直接相减。

实际版本与实际规划年度使用明确的 A00 / DUMMY_PLANYEAR 业务映射。若目标模型使用不同角色或语义，应确认兼容变体，不能因名称相似就套用本合同，也不能把实际侧一起改为预算计划年度。

全年、季度、YTD 和特殊录入/规划期间尚未纳入 v1 查询模板。扩展前核实时间层级、累计规则与规划值含义，避免月/季/年父子汇总重复，不能把某年 12 月记录自动解释为年度预算。

## 当前科目集合

| 业务编码 | 含义 |
| --- | --- |
| AC0412010000 | 生产成本－材料成本 |
| AC0412020000 | 生产成本－人工 |
| AC0412030000 | 生产成本－折旧费用 |
| AC0412040000 | 生产成本－其他费用 |
| AC0412050000 | 代工费 |
| AC0412060000 | 委外加工成本 |

这六类为当前合同的独立成本分类。模型可能还包含其他费用科目，但“生产成本六类”不能冒充所有期间费用、收入或投资；新增范围时扩展合同和验证，不按客户复制技能。ACCOUNT 的技术层级和这些编码对应的唯一名均从当前模型精确映射。

全部选择的预期集合为这六类，单科目选择为该一类。查询遗漏成员时不能按剩余行重定义预期集合。父级汇总、分类和明细不能再次混加。组织候选必须覆盖本次成本范围及预算/实际两侧，不能用材料成本的组织候选代表所有科目。

## 金额和其他维度

报告币种的金额必须由源模型提供；显示单位元、万元、亿元只按 1、10,000、100,000,000 换算，不执行汇率换算。货币不同的结果不能直接汇总或比较。

查询前还需定向核实 OBJECT、AUDITTRAIL 等模型其他维度的默认聚合是否对本次范围安全。如需约束，使用本次映射中的 `fixed_slicers` 同时下发两侧；预算/实际需要不同语义时先扩展合同，不能擅自使用同一默认值。

字段合同兼容、查询结果完整、业务完整/已关账分别检查。模型合同和样本行都不能证明金额长期不变或数据已经审核。
