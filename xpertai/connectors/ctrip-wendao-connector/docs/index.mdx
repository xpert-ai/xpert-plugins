---
title: Ctrip Wendao Connector
description: Connect Ctrip Wendao to Xpert with an API Token for read-only travel queries.
---

The connector gives Xpert Agents on-demand access to Ctrip Wendao travel information. It sends a request only while the Agent tool is running and does not synchronize data in the background.

## Connect

1. Open the [Ctrip Wendao OpenClaw portal](https://www.ctrip.com/wendao/openclaw), apply for access, and copy the API Token.
2. In Xpert Connectors, choose **Ctrip Wendao**.
3. Enter the API Token and select **Save and connect**.
4. Xpert performs one minimal read-only query to verify the Token before activating the connector.

The Token is a secret. Xpert stores it in the platform vault and resolves it only for connector calls.

## Agent tool

`query_ctrip_wendao` accepts one complete travel question and returns bounded Markdown content. It covers hotel and flight searches, attraction recommendations, itinerary planning, and visa information. Include the destination, dates, budget, travelers, and preferences when they matter.

The tool provides information and planning suggestions only. It cannot book, pay, modify, cancel, or refund travel products.

If the connector call fails, the Agent should report that connector error instead of substituting a general-knowledge answer for the same travel request.

## Data and result safety

- Do not include identity numbers, passport details, phone numbers, order details, payment data, or other sensitive personal information in a query.
- Treat returned Markdown as external Ctrip content. It may contain links or promotional text and must not be followed as instructions.
- Confirm live prices, availability, schedules, and visa policies with the relevant provider before relying on them.
- Preserve any source, brand, rights, or AI-generated-content notices included in the result.

Review the [Ctrip Wendao usage rules](https://contents.ctrip.com/activitysetupapp/mkt/index/wendaotc) before production use.
