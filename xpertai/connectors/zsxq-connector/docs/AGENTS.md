# Documentation project instructions

## Scope

This is the Mintlify documentation site for `@xpert-ai/plugin-zsxq-connector`. Document the shipped connector, its official CLI authentication flow, strict tool boundaries, and operational requirements.

## Terminology

- Use “Knowledge Planet” in English and “知识星球” in Chinese.
- Use “Workspace Files”, “工作区文件”, “Agent”, “Xpert HITL” and “设备授权” consistently.
- Refer to the pinned CLI as `zsxq-cli@0.5.1`.

## Content boundaries

- Never include real device codes, OAuth tokens, cookies, tenant IDs, or deployment credentials.
- Do not recommend cookie scraping or undocumented private endpoints.
- Link provider behavior to official Knowledge Planet sources where available.
