单元测试使用真实 CSV、JSON、XLSX 字节及实际 Worker 入口，覆盖精确求和、筛选、源文件替换、保存后的 Binding 重用、输出类型、权限撤销、目录隔离、非法路径、取消、结构变化、公式、压缩包大小限制、伪造 ZIP 大小及流式/未压缩 ZIP 的兼容性。构建后运行仓库插件生命周期测试，确认产物可以加载。

本地验收需要在已发布测试 Assistant 的文件工作区配置三种等价来源，通过真实 Chat 一句话生成看板，核对已知总额与明细，切换筛选，通过 Files 更新源文件后刷新，关闭/重开资源卡片并刷新宿主页面。确认 Artifact 和 Binding 保留，取数使用更新后的文件。

撤销当前访问者的来源或文件权限后，发现与已保存查询都应失败；恢复后重新取数。另验证未知 Binding、额外控件、文件或 payload 覆盖、浏览器直接请求后端和访问父 DOM 均不能绕过边界。

机器路径、账号和验收资源 ID 只保存在本地回执中。协议测试、加载成功和本地应用验收是不同层次，本批不进行正式发布验证。

## 2026-10-18 本地补验

在 xpert-pro 中，使用现有真实模型，分别对 CSV、JSON、XLSX 发出一条 Chat 业务请求，生成独立 HTML/ECharts 看板；没有提供预制 HTML 或脚本。三份草稿均通过 KPI、图表系列、明细、区域筛选、工具栏刷新、页面内刷新、资源卡片重开及刷新浏览器后恢复的 UI 验收。

独立测试数据包含 7 条输入、6 个月份/区域分组：总额 5,700 元，华东 3,500 元，华西 2,200 元。分别将 CSV/JSON/XLSX 首条源金额增加 100/200/300 元，刷新后的华东总额为 3,600/3,700/3,800 元；当前筛选及已挂载页面保持不变。测试后已恢复源文件。

保持同一个访问者 JWT，撤销 Assistant 文件访问或 DATA_SOURCE_VIEW 后，三种格式的发现和查询均拒绝；恢复权限后下一次请求成功。测试访问者没有继承工作区成员权限，临时授权已清理。已保存看板拒绝未知 Binding，以及文件、读取配置、Provider、payload 和未知控件覆盖；页面直接请求后端和读取父 DOM 均被拒绝。

以上仅覆盖本地 xpert-pro，不代表新一轮 data-xpert SSO 或正式发布验证。文件适配器的 20 项测试单独通过。真实模型可能需要根据工具错误自行修复；必须取得保存回执，页面验收仍需核对业务语义。

新会话生成的三来源看板也通过共同筛选与源文件更新的页面验收。另一看板经两轮修改，保持同一 Artifact、草稿、Bindings、控件和依赖锁（检查时点修订 r1 → r3 → r5）；最终稿通过相同的刷新与重开验收。初轮失败及后续补验分别保留在看板插件 `docs/file-datasets-acceptance.mdx` 中。
