Add optional standard-dashboard theme settings and map host color/font tokens into the isolated renderer. Follow host theme changes without modifying saved bindings or query results. HTML-authored dashboards retain their own presentation styles.

**Beta:** Theme keys, token mappings, and the persisted `visualTheme` field may change incompatibly at any time during beta; backward compatibility is not guaranteed.
