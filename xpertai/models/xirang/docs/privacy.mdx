# 隐私与数据处理

## 数据流向

本插件是天翼云星辰 MaaS 的模型适配层，不建立独立的数据存储或遥测服务。启用模型后，Xpert 会按照所选模型类型，将请求内容、模型参数和必要的上下文发送到配置的天翼云 API 地址；天翼云的处理和保留规则以天翼云服务协议及隐私政策为准。

凭据校验会向天翼云的 `/models` 端点发送一次带 AppKey 的请求。AppKey 由 Xpert 的系统集成或模型供应商凭据管理，不写入插件源码、目录快照或日志。

## 个人数据

插件本身不主动收集用户姓名、邮箱、手机号、IP 地址或设备标识。用户在请求中主动提交的个人信息可能随请求内容发送至天翼云，使用前请依据组织的数据分类、授权和合规要求进行评估。

## 凭据与日志

- AppKey 仅用于请求鉴权，不在插件日志中输出。
- 插件不向第三方分析服务发送数据。
- Xpert 主机的凭据加密、访问控制、审计和日志策略继续适用。
- 组织管理员应根据天翼云账户权限配置可使用的模型，并在不再需要时撤销或轮换 AppKey。
