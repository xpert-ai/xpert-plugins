---
title: 内部架构
description: Provider、模型适配器和目录生成流程
---

```text
XirangProviderStrategy
  ├─ AppKey + endpoint_url 校验（GET /models）
  ├─ XirangLargeLanguageModel
  │    └─ ChatOAICompatReasoningModel + streamUsage + token ledger callback
  ├─ XirangTextEmbeddingModel
  │    └─ OpenAIEmbeddings + 原始 Authorization AppKey
  ├─ XirangRerankModel
  │    └─ POST /rerank
  └─ XirangImageGenerationModel
       └─ POST /images/generations（模型特有字段透传）
```

`scripts/generate-catalog.mjs` 是目录的唯一生成入口。它从内联服务快照过滤下线模型，按名称识别 LLM、Embedding、Rerank、图片和视频，再输出排序文件、模型 YAML 和归一化审计快照。
