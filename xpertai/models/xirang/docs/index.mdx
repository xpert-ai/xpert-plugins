## 快速开始

在模型 Provider 配置中填写天翼云星辰 AppKey。默认端点是 `https://ai.ctaigw.cn/v1`，如果租户使用专属网关，可以填写自定义端点。

插件会从目录快照生成预置模型，并过滤标记为“（即将下线）”的服务。保存凭据后使用“校验凭据”，再在 Assistant 中选择模型即可。

## 当前目录

目录来源是天翼云星辰内联服务页面。模型名称、模型 ID 和分类元数据保存在 `src/catalog/source.snapshot.json`，分类和下线过滤结果保存在 `src/catalog/normalized.snapshot.json`。

视频服务目前只记录在审计清单中。天翼云的视频接口需要稳定的异步任务提交、查询和回调契约，确认后再开启运行时，避免出现能选中但必然调用失败的模型。
