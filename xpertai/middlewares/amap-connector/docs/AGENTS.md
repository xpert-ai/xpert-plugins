# Documentation project instructions

## About this project

- This is the Mintlify documentation site for `@xpert-ai/plugin-amap-connector`.
- Pages are MDX files with YAML frontmatter.
- Configuration lives in `docs.json`.

## Terminology

- Use “AMap” in English and “高德地图” in Chinese.
- Use “Web Service Key”, “数字签名私钥”, “工作区”, and “Agent” consistently.
- Coordinates are always written as `{ lng, lat }` in GCJ-02.

## Style preferences

- Use active voice and concise sentences.
- Use sentence case for headings.
- Use bold for UI labels and code formatting for file names, commands, paths, and identifiers.

## Content boundaries

- Document only the shipped connector and its read-only tools.
- Never include real Keys, private keys, signatures, tenant IDs, or internal deployment credentials.
- Link to official AMap documentation for provider-specific behavior.
