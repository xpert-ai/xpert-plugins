# Exa for Xpert

An Xpert-authored Agent Plugins 1.0.0 package for the official
[Exa remote MCP server](https://exa.ai/docs/get-started/exa-mcp).
It is not a copy of the Codex plugin or an Exa-published package.

Import this directory as a ZIP or Git subdirectory, publish it to a workspace,
without configuring a Connector. Select **Exa** in the conversation plugin menu.
Try: "Use Exa to find the official Agent Plugins specification and cite its URL."

No API key is required for the provider's starter access. Provider limits still
apply. Only queries and requested public URLs are sent to Exa. Paid account tools
and API-key configuration are outside this preset.
