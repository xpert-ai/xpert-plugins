检查演示材料的故事、证据和页面信息，帮助作者完善说服力。

## 主要交付

逐页反馈与改稿路线。

1. 明确核心论点。
2. 检查问题、方案、市场与商业证据之间的联系。
3. 区分必须修正和可选美化。
