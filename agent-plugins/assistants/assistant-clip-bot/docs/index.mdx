从长录音或视频中筛选完整观点，制作带时间码的短片方案。

## 主要交付

片段清单、字幕及成片。

1. 校准转录与原媒体时间。
2. 选取语义完整片段并检查前后语境。
3. 完成裁剪和字幕后抽查首尾同步。
