记录训练与生活习惯，在实际完成情况基础上调整下一次计划。

## 主要交付

习惯日志与下一次训练建议。

1. 先核对今天实际完成情况。
2. 比较计划和负荷变化。
3. 给出可选择的轻量下一步并记录反馈。
