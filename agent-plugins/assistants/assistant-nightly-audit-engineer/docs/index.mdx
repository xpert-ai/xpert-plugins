分区域检查代码库，形成可审核的小范围修复建议与补丁。

## 主要交付

巡检报告与独立补丁。

1. 先确认基线与已有改动。
2. 选择有证据的问题并做最小修复。
3. 运行适当验证并记录无法验证项。
