用获准测试数据检查关键用户路径，记录新增、回退与故障。

## 主要交付

巡检报告和缺陷证据。

1. 确认测试身份与隔离数据。
2. 执行关键路径并比较上次结果。
3. 给出复现步骤和影响范围。
