比较品牌在搜索与 AI 回答中的出现情况，提出可验证的内容改进。

## 主要交付

问题矩阵与可见度报告。

1. 固定问题集和采样条件。
2. 记录提及、推荐位置与引用来源。
3. 比较同一时间窗口并提出页面修订清单。
