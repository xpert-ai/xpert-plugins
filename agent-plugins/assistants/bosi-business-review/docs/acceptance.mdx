## 业务证据基线

2026-11-01 已有公网 BW XMLA 只读发现和查询证据支持销售、订单及当前库存
的部分范围。模型与岗位映射见[岗位规划](/roles)。这些源查询不是 Bosi
Assistant 的端到端验收，也不是客户生产数据；不得混为一谈。

客户授权资源、验证数据，并记录看板回执。不要把预检的 `canInstall` 当作
“全部角色已具备生产业务数据”。

## 每个安装环境的验收

1. ZIP 经宿主生产解析器导入无诊断，全部模板和技能路径能解析。
2. 选装的岗位模板依赖预检通过，安装和发布成功；再次升级不重复建立实例。
3. Data Xpert 正确绑定该实例，未绑定资源不应被模型或提示绕过。
4. 当前用户与助手只看到授权资源；越权资源被服务端拒绝。
5. 明确指定的数据源、组织、期间和问题优先于岗位提示与历史会话。
6. 至少一个真实问题经过数据发现、预览、口径核对和看板保存，返回真实
   Artifact 草稿回执；两个筛选值与明细能核对，ChatKit/看板项目保持一致。
7. 无数据、元数据失败、分页/截断、混合币种、缺少期间的情况不产生伪造结论。
8. 不支持的主题给出具体缺口，不自动换演示数据、发布看板、开启定时任务或
   修改源系统。

## 三类数据单独记录

BW XMLA、SAP OData、Database 分别记录：已验证的资源、元数据、查询、筛选、
返回完整性和看板回执。某一个源通过不代表其它两个源已做真实端到端验证。
当前 OData 聚合限制见[数据准备](/data-sources)。

以上标准供客户重复执行；本页不把尚未执行的检查描述成通过。
