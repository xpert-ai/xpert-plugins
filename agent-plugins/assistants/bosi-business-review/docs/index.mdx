Bosi 帮助经营人员从授权数据中发现值得讨论的问题，再按需要制作实时看板。
一个 Assistant 可以分析多个主题、使用多个授权数据源并制作多个看板。

## 三层分工

| 层次 | 决定什么 | 不决定什么 |
| --- | --- | --- |
| 岗位模板 | 决策重点、默认追问、结果表达和开场提示 | 数据访问权、固定主题列表 |
| 共享 Skills | 数据探索、指标口径、分析步骤、证据与看板制作 | 客户数据源、真实模型 ID |
| 客户实例与资源授权 | 谁能使用、可访问哪些业务模型和数据范围 | 自动改变源系统权限 |

常用入口有 CEO、CFO、销售经理、采购经理、供应链经理、生产经理；成本控制、
资金管理、应收管理和项目经理按客户实际岗位选装。通用 Bosi 入口可覆盖兼岗
人员，不要求为每个职称建立实例。详见[岗位规划](/roles)。

## 第一次使用

管理员[安装模板并绑定数据](/usage)，用户在 ChatKit 选择或创建项目，然后提出
业务问题，例如：

> 请分析上个已结账月华东销售组织的销售变化，找出客户和商品贡献最大的变化；
> 使用公司的销售模型，先解释发现，再制作看板草稿。

助手核对实际模型与口径、查询证据、选择有数据支撑的主题，再保存真实的看板
草稿。数据不足时说明具体缺口；不会用演示数据替代。制作依然发生在 ChatKit
与 Live Dashboard 中，Project 负责组织会话和成果。

## 交付边界

套件提供分析方法和岗位模板，不附带客户凭据、生产数据或模型访问权。看板
草稿的保存与正式发布分开；安装套件不会自动开启月度任务，也不会修改 SAP
订单、支付、财务凭证或向他人发送报告。查看[当前验收范围](/acceptance)。
