| 数据类型 | 客户准备 | 助手的使用方式 | 重点检查 |
| --- | --- | --- | --- |
| BW XMLA / SAP BW 查询 | 连接、已发布语义模型或本体资源、变量与组织授权 | 发现真实 Cube、维度、度量、参数，再执行受治理的分析动作 | 必填变量、层级成员、期间、币种、金额与百分比语义 |
| SAP OData | 已注册并授权的 SAP OData 资源与服务元数据 | 使用发现返回的只读实体/集合动作 | 实体键、关联粒度、分页、过滤能力和金额单位 |
| Database | 连接及发布的数据模型，或已授权的原生只读分析源 | 以模型契约或允许的查询能力读取 | 表关联、去重订单、方言、单位、取消/冲销与完整性 |

Data Xpert 的 analytics provider 通过当前用户和当前 Assistant 的授权共同
约束资源。连接、模型发布、Assistant 绑定与 Project 选择是不同步骤；成功
连接不能证明该助手有权读取所有模型，创建分析定义也不会增加访问权。

## 当前 OData 限制

当前 Data Xpert Live Artifact OData 路径不支持 `$apply` 聚合。不要生成该
能力不存在的查询；一页数据、截断数据和全量聚合必须区分。需要整体支出或
排名时，使用已发布的适当聚合模型、完整且受限的数据范围，或说明当前无法
给出全量结论。不得绕过工具改用直连 fetch 或源系统凭据。

## 指标不是按名称自动可用

- 销售利润金额不等于利润率，也不等于企业净利润。
- 订单项目数不等于去重订单数。当前交付状态不代表过去月末状态。
- 库存快照不能独立计算周转率、库龄或库存趋势。跨币种不可直接求和。
- 生产报废数据不能独立计算 OEE；工序时长也不等于产能利用率。
- 采购支出下降不等于采购节约，供应商份额不等于准时交付率。
- 计划、目标、实际与完工估算需要明确版本。业务项目/WBS 与 ChatKit Project
  分别处理。

## 常见阻塞

| 表现 | 优先检查 |
| --- | --- |
| 没有可用来源 | Integration、分析定义、模型发布、Assistant 资源绑定 |
| Unknown business assistant runtime | 是否已在 Data Xpert 绑定正确的已发布实例与 AI Workspace |
| 资源不可见 | 当前用户权限、Assistant 资源范围、业务领域与组织匹配 |
| BW 必填参数或货币转换错误 | 查询变量、币种/汇率配置；不可悄悄换成其他口径 |
| 元数据有模型但查不到数据 | 期间、过滤条件、数据装载、源系统授权；空结果不是零 |
| OData 汇总明显偏小 | 是否只读了一页、返回了截断数据，是否缺少聚合能力 |
| 无法做某主题 | 列出缺少的概念、字段和资源，继续回答其它已支持的问题 |

具体资源选择以用户问题为准。角色模板中的默认重点与本次 BW 目录发现都
不能代替生产系统的实时元数据与权限校验。
