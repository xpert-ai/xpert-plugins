跟踪目标企业职位变化，为客户研究提供可追溯的经营线索。

## 主要交付

职位变化与客户线索简报。

1. 核对职位发布日期与重复招聘页。
2. 比较岗位方向和数量变化。
3. 附来源并说明可能解释。
