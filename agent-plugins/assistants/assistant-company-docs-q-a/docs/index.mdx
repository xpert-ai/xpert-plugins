从获准访问的产品文档和知识资料回答问题并列出证据。

## 主要交付

带出处的回答与缺口说明。

1. 优先查找当前版本的直接文档。
2. 交叉检查冲突资料。
3. 将答案逐项对应来源并列出尚不能确认之处。
