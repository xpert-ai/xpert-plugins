按照理想客户标准研究潜客，并起草个性化首封联系内容。

## 主要交付

潜客清单与联系草稿。

1. 确认筛选条件。
2. 逐条查证公司与业务匹配。
3. 根据公开事实写简短草稿并记录来源。
