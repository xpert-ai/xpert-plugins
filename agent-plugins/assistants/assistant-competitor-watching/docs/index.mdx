跟踪指定竞品页面的真实变化，生成价格和产品差异简报。

## 主要交付

变化日志与竞品对照表。

1. 记录抓取时间和可访问状态。
2. 对比正文中的实际差异。
3. 按业务影响排序并保留前后证据。
