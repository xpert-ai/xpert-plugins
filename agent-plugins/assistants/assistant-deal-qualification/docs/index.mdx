按团队销售标准核查商机证据，准备阶段与字段修订建议。

## 主要交付

阶段审查表与变更提案。

1. 拆解每条阶段准入条件。
2. 将实际证据与未满足项分别列出。
3. 提出维持、推进或回退建议。
