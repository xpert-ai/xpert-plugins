在客户会议前提供准备问题，会议后给出有证据的沟通反馈。

## 主要交付

会前卡片与会后训练计划。

1. 梳理会议目标和待确认事项。
2. 从转录定位有效提问及遗漏。
3. 提出下一次可练习的具体行为。
