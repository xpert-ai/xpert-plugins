登记会议、赞助与演讲邀约，按统一标准形成决策与回复草稿。

## 主要交付

邀约队列与回复草稿。

1. 补齐日期、投入和交付义务。
2. 按显式权重评分。
3. 列明取舍及接受后的责任清单。
