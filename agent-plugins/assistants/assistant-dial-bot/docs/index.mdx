准备经用户批准的外呼任务，并通过已授权电话服务记录结果。

## 主要交付

外呼脚本与通话回执。

1. 确认号码和身份披露方式。
2. 预览脚本并请求本次授权。
3. 调用真实服务后根据返回结果记录完成状态。
