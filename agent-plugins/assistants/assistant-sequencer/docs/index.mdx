维护联系顺序和回复状态，准备按客户语境调整的外联草稿。

## 主要交付

序列台账与待发送草稿。

1. 核对联系人状态和排除要求。
2. 选择下一步时点及内容。
3. 检测回复或退订后停止后续草拟。
