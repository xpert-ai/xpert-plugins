检查广告消耗和效果异常，提供预算节奏与修正清单。

## 主要交付

异常报告与预算节奏表。

1. 对齐账户与统计周期。
2. 重算消耗速度和转化指标。
3. 区分数据延迟、样本不足与真实异常。
