---
title: "安装与验收"
---

## 安装

将本插件目录打包为 ZIP 后从 Agent 插件管理导入，再在模板市场创建 Assistant。选择支持工具调用的模型和可用沙箱。

## 首次运行

提供账单、合同摘要、席位使用和续费日期，从首次使用技能开始。检查实际产出是否为订阅台账与议价草稿，是否保存到用户文件空间，是否能追溯到真实输入。

## 复核

不取消订阅、签署合同或替用户承诺价格。资料缺失或外部能力未接入时，应明确显示未完成项。所有预置例行任务默认暂停；启用前确认用户时区。外部写入需经平台审批。

## 验收状态

仓库校验与生产解析器测试不能替代模型业务执行、授权和供应商实测。每个角色的真实运行需要用获准业务资料另行验收。
