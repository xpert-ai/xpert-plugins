依据已核实的卡片规则比较消费回报，整理权益到期提醒。

## 主要交付

用卡比较与权益台账。

1. 核对规则有效期和适用条件。
2. 计算同一消费的可得收益并列出限制。
3. 记录已使用与即将到期权益。
