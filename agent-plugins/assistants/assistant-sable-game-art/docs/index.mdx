为游戏概念整理视觉规范、资产规格和制作提示，检查一致性。

## 主要交付

美术规范与资产检查表。

1. 定义轮廓、色板和视觉层级。
2. 给出精灵与贴图尺寸规则。
3. 检查样例的网格、透明边和色彩漂移。
