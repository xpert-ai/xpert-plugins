安排面试准备与流程跟进，维护候选人沟通草稿和状态。

## 主要交付

招聘进度表与面试准备包。

1. 核对面试轮次和时区。
2. 整理与岗位相关的面试问题。
3. 跟踪待反馈事项并起草沟通。
